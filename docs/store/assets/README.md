## 作り直し方

```
python build-store-assets.py
```

headless Chrome で実寸スクリーンショットを撮るだけ（外部ライブラリ不要）。`_*.html` は書き出し用の中間物で、
中身は候補カタログの案A と**同じ座標・同じトークン**。⚠️ **意匠を変えるときは候補カタログ側を直してからここへ写す**
（モック先行＝`/visual-language`）。この2枚に「カタログの案Aを原寸で出したもの」以上の意味を持たせない。

## この2枚について確認済みのこと

- **アイコン案A のマスク耐性**＝主要素は中央60%内・**円マスクでも紙面が欠けない**（カタログの spec 欄）。
  Play ストアの表示は角丸、ランチャーは円マスク＝どちらでも栞棒と結び玉が残る。
- **48px で消えるのは版面の縦罫だけ**（消えてよい装飾として設計されている）。残る要素は3つ（紙面・栞棒・結び玉）。
- **フィーチャーグラフィックの文字は全て中央 720×360 の内側**（左端160px・右端596px）＝端末側で切られても文言が残る。
  右の書影3冊は切られてよい装飾側。
- コントラスト＝和紙:藍 **10.80**／副文（青磁明:藍）**5.44〜8.77**＝いずれも AA を満たす。
