## 3. 詳細な説明（4000字上限）

> ▼本文ここから▼（そのまま Console に貼れる状態。**現在 1,255字**／上限 4,000字）

Yosari（夜さり）は、Web小説を「紙の本のように」読むための小説リーダーです。

小説家になろうが配布している縦書きPDFを取り込み、ふりがな（ルビ）が付いたまま、アプリ独自の縦書き描画で表示します。ブラウザの横書きでは読みにくかった長編も、行間・文字サイズを自分に合わせて、落ち着いて読み進められます。

■ 主な特長

・ふりがな付きの縦書き表示
　なろうの縦書きPDFを取り込むと、ルビを保ったまま縦書きで読めます。画像ではなく文字として組み直すので、文字サイズや行間を変えても崩れません。横書き表示にも切り替えられます。

・取り込んだ作品はオフラインで読める
　電波の無い場所でも、通勤中でも、続きから読めます。読書位置は自動で記録され、次に開いたところから再開できます。

・広告が一切ありません
　読書中に広告が割り込むことはありません。アプリ内の広告表示そのものがありません。

・アカウント登録が不要
　メールアドレスも会員登録も必要ありません。蔵書・読書位置・設定はすべて端末の中に保存され、こちらのサーバーへ送られることはありません。

・本棚で蔵書を管理
　読みかけ・読了などの状態で絞り込み、並べ替えて探せます。目次では既読の話に印が付き、読みかけの位置からすぐ再開できます。

・新着のお知らせ（初期設定はオフ）
　設定でオンにすると、本棚に入れた作品の新着話を1日1回だけ確認してお知らせします。

■ 対応しているサイト

・小説家になろう … 公式APIによる検索・ランキング閲覧、公式サイトの表示、公式の縦書きPDFの取り込み
・カクヨム、暁 … 作品の取り込み（アプリ内で読めます）

※ 小説家になろうのページは、加工せずそのまま表示します。作品の取り込みは、なろう自身が用意している縦書きPDFのダウンロードを、その都度あなたの操作で行う形をとっています。

■ こんな方に

・スマートフォンでも縦書きで小説を読みたい
・ふりがなの付いた作品を、ルビごと読みたい
・広告に邪魔されずに読書に集中したい
・移動中など通信できない場所でも続きを読みたい

■ プライバシーについて

このアプリは、利用者のデータを集めるためのサーバーを持っていません。分析（アクセス解析）SDK も広告 SDK も入れていません。通信するのは、作品を検索するとき・サイトを表示するとき・作品を取り込むときだけで、いずれもあなたの操作に応じてその場で行われます。詳しくはプライバシーポリシーをご覧ください。

■ ご注意

・本アプリは個人開発の非公式アプリです。株式会社ヒナプロジェクトが運営する「小説家になろう」、および各小説投稿サイトの公式アプリではありません。運営各社とは関係がありません。
・各サイトの仕様変更により、取り込みや検索が一時的に利用できなくなる場合があります。
・取り込んだ作品の本文は、あなたの端末の中だけに保存されます。他の人と共有する機能はありません。

## 4. スクリーンショット（最低2枚・推奨6枚／各1080×1920 以上）

**全て「明快K」（公開ビルドの既定UI）で撮る。** きせかえが写り込む画面は撮らない。

| # | 画面 | 乗せる文言（画像上のキャプション） | 意図 |
|---|---|---|---|
| 1 | **縦書き読書中（ルビが見える段）** | 「ふりがな付きのまま、縦書きで」 | ★最大の差別化。競合（カクヨム公式ですら縦書き非対応）に無い一点を1枚目に置く |
| 2 | 本棚（グリッド・書影あり） | 「読みかけも読了も、本棚で」 | 蔵書管理＝日常の画面。アプリの佇まいが伝わる |
| 3 | さがす（検索・ランキング） | 「なろうの検索とランキングから」 | 発見導線があることを示す（＝取り込み専用ツールではない） |
| 4 | 目次（現在地チップ・既読✓） | 「どこまで読んだか、ひと目で」 | 長編を読む人の実利 |
| 5 | 読書設定（文字サイズ・行間のライブプレビュー） | 「文字の大きさも行間も、自分好みに」 | 読書アプリの評価軸そのもの |
| 6 | 読書中（没入・UIが引いた状態） | 「広告なし。読むことだけに」 | 広告過多の競合への当て |

⚠️ 1枚目は**公開後の A/B テスト（ストアリスティング テスト・Console 内蔵で無料）の最有力候補**。ただし戦略書 §2 のとおり、テストは**ストア訪問が日に数十人**になってから。初回は一発案で出す。

## 5. フィーチャーグラフィック（1024×500・必須）

**確定＝A「夜の帯」**（2026-08-20 裁定。正本＝`docs/design-candidates/store/store-feature-graphic-candidates.html` の A 節）。

| 項目 | 確定値 |
|---|---|
| 構図 | 藍から濃紺へ沈む夜の面。左に和紙色のロゴ（`Yosari` ＋「よ さ り」）、その下に一行コピー、右に栞書影を3冊流す |
| 一行コピー | `縦書きで読む、Web小説。` |
| 色 | 地 #24435F→藍 #1C3D5A→濃紺 #0E2030／和紙 #FBFAF8／青磁明 #A9C2BB／朱明 #CC8B73 |
| 文字の位置 | 左端 160px・右端 596px＝**中央 720×360 の内側に全収まり**（端の切り落としで文字が欠けない） |
| コントラスト（実測） | ロゴ・コピー（和紙 : 藍）= 10.80 以上／副文（青磁明 : 藍）= 5.44〜8.77（最悪値でも AA 4.5 を満たす） |

- ⚠️ **端末フレームの写真を大きく置かない**（この枠はテキストが小さくなると読めない）。
- ⚠️ ストアでは自動再生の動画があるとこの画像が隠れることがある＝動画は初回は用意しない前提。
- 残作業＝**1024×500 PNG の書き出し**のみ（制作は 2026-08-20 にユーザー判断で見送り＝積み）。

## 6. アイコン（512×512・32bit PNG）

**確定＝A「栞書影（しおりしょえい）」**（2026-08-20 裁定。正本＝`docs/design-candidates/store/store-icon-candidates.html` の A 節）。
下の「方向性」は選定の経緯として残す。

| 項目 | 確定値 |
|---|---|
| 造形 | 夜の地に和紙の一冊。**アプリが本棚で描いている書影（紙地＋細い栞棒＋結び玉）をそのまま縮図にした**＝アイコンと中身が一致する唯一の案 |
| 色 | 藍 #1C3D5A→#0E2030／和紙 #FBFAF8／朱 #A1573F |
| コントラスト（実測） | 和紙 : 藍 = 10.80／朱 : 和紙 = 5.10 |
| 48px での要素数 | 3（紙面・栞棒・結び玉）※縦罫は消える設計 |
| マスク耐性 | 主要素は中央 60% 内＝**円マスクでも紙面が欠けない** |

- 方向性（選定の経緯）＝**「夜」と「栞」**。`Yosari`＝夜さり（古語で「夜」）に由来し、屋号 `Colophon`（奥付）とは別軸で「読む時間」を名前にしている（README §2）。
- ⚠️ 競合は「本」「W」「吹き出し」系が多い（戦略書 §3）＝**濃い夜色の面**は一覧の中で目を引く側に倒れる。
- 残作業＝**512×512 PNG の書き出し**のみ。
