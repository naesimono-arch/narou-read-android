# Yosari プライバシーポリシー

制定日: 【公開日】
提供者: Colophon

Yosari（以下「本アプリ」）は、Web小説を読むための Android アプリです。本ポリシーは、本アプリがどのような情報を扱い、どのような通信を行うかを説明するものです。

## 1. 基本方針

- 本アプリに**アカウント登録機能はありません**。氏名・メールアドレス等の個人情報の入力を求めることはありません。
- 提供者は、利用者のデータを収集・蓄積するためのサーバーを**運営していません**。読書履歴・蔵書・設定などのデータは、すべて利用者の端末内に保存されます。
- 本アプリは、**分析（アクセス解析）SDK および広告 SDK を含みません**。

## 2. 本アプリが外部と通信する場面

本アプリは、以下の場面で外部のサーバーと通信します。いずれも利用者の操作（または利用者が有効にした設定）に応じてその場で行われる通信であり、提供者がその内容を受け取り、記録・蓄積することはありません。

| 場面 | 通信先 | 送受信される主な情報 |
|---|---|---|
| 作品の検索・ランキング閲覧 | 小説家になろう公式 API（api.syosetu.com） | 検索条件（キーワード・ジャンル等）と、その結果である作品情報 |
| 小説家になろう公式サイトの表示・縦書きPDFの取得 | syosetu.com の各サイト | 通常のウェブ閲覧と同様の情報（閲覧するページの URL 等） |
| 対応サイトからの作品取り込み（利用者の明示的な操作時のみ） | カクヨム（kakuyomu.jp）・暁（www.akatsuki-novels.com） | 利用者が指定した作品ページの取得要求と、その作品の本文 |
| 新着話チェック（初期設定は無効・利用者が有効にした場合のみ 1日1回） | 小説家になろう公式 API／カクヨム（kakuyomu.jp）・暁（www.akatsuki-novels.com）の作品ページ | なろうの本は作品の識別番号（Nコード）と最新話数。カクヨム・暁から取り込んだ本は、その取り込み元の作品ページ URL と目次 |
| アプリの評価の打診（初めて1作を読み終えたときに1回だけ表示。無視できます） | 端末の Google Play（Google Play 開発者サービス経由） | 評価画面の表示要求のみ。入力された評価・レビューは Google Play が直接受け取るもので、**評価したかどうかを含め本アプリには何も返りません**。蔵書や読書記録が送られることもありません |

これらの通信に伴い、接続先のサーバーは IP アドレスや端末環境などの技術的な情報を受け取ります。これらの情報の取り扱いは、各サイト運営者のプライバシーポリシーに従います。

## 3. 端末内にのみ保存される情報

以下の情報は利用者の端末内にのみ保存され、外部へ送信されません。

- 蔵書（取り込んだ作品の本文）・本棚の登録内容
- 読書位置・しおり・読了状態
- 表示テーマ・文字サイズなどの設定
- 動作診断情報（アプリが異常終了した際の記録や描画性能の統計。**外部送信は行われず**、端末内に上限件数付きで保存されます）

## 4. 外部サイトの表示と Cookie について

本アプリは、小説家になろう等の外部サイトを、アプリ内ブラウザ（WebView）または端末のブラウザで**加工せずそのまま**表示します。表示されるページ内の Cookie や広告等は、各サイトおよびその広告事業者によって取り扱われるものであり、本アプリがこれらを収集・蓄積・改変することはありません。

なお、小説家になろうの縦書きPDFを取り込む際に限り、ダウンロードを正しく完了させるため、アプリ内ブラウザが保持する当該ダウンロード URL の Cookie を、**同じサイトへのダウンロード要求にその場で引き継ぎます**。この Cookie を他の送信先へ送ること、およびアプリが保存することはありません。

## 5. バックアップ（Android の自動バックアップ）

本アプリは Android 標準の自動バックアップ機能（Auto Backup）に対応しています。

- バックアップの対象: 本棚の登録内容・読書位置・しおり・設定などのメタデータ
- バックアップの対象外: 取り込んだ作品の本文
- バックアップデータは、利用者の Google アカウントに紐づく Google のサーバーに保存されます。この機能は Android OS が提供するもので、端末の設定（「バックアップ」設定）からいつでも無効にできます。提供者がバックアップデータの内容にアクセスすることはありません。

## 6. 通知

新着話のお知らせ通知は**初期設定で無効**であり、利用者が設定で有効にした場合にのみ動作します。通知は端末内で生成されるローカル通知であり、外部のプッシュ通知サービスは使用しません。

## 7. 第三者提供

提供者が利用者の個人情報・利用データを第三者に提供することはありません（前述のとおり、そもそも提供者はこれらのデータを取得していません）。

## 8. データの削除

- 端末内のデータは、本アプリのアンインストール、または端末設定からのアプリデータ消去により、すべて削除されます。
- 自動バックアップのデータは、Google アカウントのバックアップ管理（Google の提供する手段）から削除できます。

## 9. 広告について（将来の変更）

現在のバージョンに広告はありません。将来、広告（リワード広告等）を導入する場合は、広告 ID の取得・広告事業者への情報提供が新たに発生するため、**導入前に本ポリシーを改定し**、Google Play のデータセーフティ申告も併せて更新した上で、アプリ内またはストアページでお知らせします。

## 10. 本ポリシーの変更

本ポリシーの内容を変更する場合は、本ページで公開します。重要な変更については、アプリ内またはストアページでもお知らせします。

## 11. お問い合わせ

本ポリシーおよび本アプリのデータの取り扱いに関するお問い合わせは、下記までご連絡ください。

## 監督への提案（公開対象外）: ホスティング先の候補比較

**決着済み**＝GitHub Pages・リポジトリ `naesimono-arch/yosari`（public）・URL `https://naesimono-arch.github.io/yosari/privacy.html`。
以下は選定の経緯（別案へ移す判断をするときのために残す）。Play 要件＝**常時公開・静的・非PDF・安定 URL**（実査 B-4）。

| 案 | 費用 | 手間 | 備考 |
|---|---|---|---|
| **GitHub Pages（推奨）** | 無料 | 小（公開用リポジトリに HTML/md を置くだけ。既に git 運用中で追加ツール不要） | 独自ドメイン任意。URL は `https://<user>.github.io/<repo>/privacy.html` 型で安定（本件＝`naesimono-arch/yosari`）。将来の特商法表記・サポートページも同居可能。注意: **公開リポジトリが必要**＝本体リポジトリとは分離した公開専用リポジトリを切る |
| Cloudflare Pages | 無料 | 小〜中（アカウント新設が要る） | 独自ドメイン運用に最も強い。ブランド名確定後に独自ドメインを取るなら乗り換え先としても有力 |
| Google Sites | 無料 | 小（GUI のみ） | git 管理外になり、下書き md との同期が手作業＝ドリフトしやすい。非推奨 |

**推奨＝GitHub Pages**。理由: 追加アカウント不要・md 正本と同じ git ワークフローで更新でき、「下書き（本ファイル）→公開版」の差分管理が自然に残る。ブランド名・独自ドメイン確定後に Cloudflare Pages へ移す判断は後からでも安い（URL は Play Console で差し替え可能）。
なお公開後は**アプリ内（設定画面等）からのリンク設置**が望ましい（完全フロー資料 §4）＝ UI 追加はモック先行ルールに従い別ラウンド。
