アプリアイコン候補（512×512）

合否は「小さくして識別できるか」の一点。各案とも 512px 実寸のほか、Play 一覧相当（96px）・ランチャー相当（48px・円マスク）・ サジェスト相当（32px）を併記し、末尾に Play 検索結果とランチャーの一覧シミュレーションを置いた。 方向性は docs/store/listing-draft.md §6「夜」と「栞」に従い、同節の具体案①②③を A・B・C に当てている。 色は明快K のトークンのみ（新規の色を発明していない）。

512×512・32bit PNG アルファなし＝全案が地色を全面に塗る 要素は中央寄せ（適応アイコンのマスク欠け対策） 金・星（M/P 系スキンの語彙）は不使用 PNG 書き出しは裁定後の別便

A

栞書影（しおりしょえい）

夜の地に和紙の一冊。アプリが本棚で描いている書影（紙地＋細い栞棒＋結び玉）を、そのまま縮図にした。
アイコンと中身が一致する唯一の案。

48px の要素数
3（紙面・栞棒・結び玉）※縦罫は消える設計
マスク耐性
主要素は中央 60% 内。円マスクでも紙面が欠けない

B. 月と本listing-draft §6 具体案② をそのまま起こした案

B

月と本（つきとほん）

三日月の下に開いた本。「夜に読む」を最短で言い切る記号型。
読書アプリだと一目で分かる代わりに、月＋本は世に多い組み合わせでもある。

使用トークン
藍 #24435F→#0E2030／和紙 #FBFAF8／青磁明 #A9C2BB
コントラスト
和紙 : 藍 = 10.80〜15.88／青磁明 : 藍 = 5.44〜8.77（いずれも地のグラデ幅ぶんの範囲・最悪値で表示）
48px の要素数
3（月・左頁・右頁）＝本案中もっとも多い
マスク耐性
本の左右端が x=96/416＝円マスクで角が削れる（欠けの見え方は円マスクで要確認）

C. 夜（一字）listing-draft §6 具体案③ をそのまま起こした案

C

夜（よる）

明朝の「夜」一字を版面の匡郭に収めた。ブランド名 Yosari＝夜さり を字そのもので名乗る。
32px まで潰れても「濃紺に白い漢字」は残る＝最も情報が減りにくい形。

使用トークン
藍 #1C3D5A→#0E2030／和紙 #FBFAF8
コントラスト
和紙 : 藍 = 10.80（匡郭のみ 24% 不透明＝装飾）
48px の要素数
1（字のみ）
マスク耐性
字は中央 65% 内。匡郭は円マスクで消えるが字は無傷
注意
書き出し時は明朝を実フォントで確定させる（環境依存の字形差が出る唯一の案）

D. 紙の栞明暗を反転させた対照案（一覧で暗色が並ぶ中、紙地が逆に目立つか）

D

紙の栞（かみのしおり）

A を裏返し、和紙の側から見た栞。既定UI（明快K）の実際の地色は和紙なので、
アプリを開いた瞬間の色と一致する。白背景の一覧で沈まないよう匡郭を1本入れてある。

使用トークン

E. よ（かな一字）文字型のもう一極＝漢字ではなく仮名。色相も藍から外した

E

よ（よさりの「よ」）

仮名一字。曲線だけでできているので、漢字より小サイズでの輪郭が残りやすい。
地は青磁ink＝競合に少ない色で、藍のアイコン群の中でも隣と混じらない。

使用トークン
青磁ink #50685C／和紙 #FBFAF8
コントラスト
和紙 : 青磁ink = 5.79（本案中もっとも低い。大きい字なので可読だが地色を暗めに寄せる余地あり）
48px の要素数
1（字のみ）
マスク耐性
字は中央 60% 内。全マスクで無傷
注意
C と同じく明朝の実フォント確定が必要

F. 結び玉紋紋型＝要素を最少にして潰れ耐性を最大化した案

F

結び玉紋（むすびだまもん）

栞の先端（結び玉）だけを抜き出して紋にした。文字も本も月も使わない抽象記号型。
栞先端の意匠は本アプリ固有の造形なので、抽象でも自社の資産に接続している。

使用トークン
藍 #1C3D5A→#0E2030／和紙 #FBFAF8／朱明 #CC8B73
コントラスト
和紙 : 藍 = 10.80／朱明 : 藍 = 4.03（朱明は装飾の芯のみ・可読要件なし）
48px の要素数
2（棒・玉）＋輪
マスク耐性
輪の直径 328＝全体の 64%。全マスクで無傷
