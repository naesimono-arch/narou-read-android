③ 幾何・エディトリアル を突き詰める 構成文法 6種

方向は③「幾何・エディトリアル」に決定。ここはその深掘りです。余白主導のクロームはそのままに、幾何の"構成文法"を6種（Ⓐ一手／Ⓑ対／Ⓒ弧の重なり／Ⓓ面・Swiss／Ⓔ線／Ⓕ円相）に展開しました。どれもタイトル駆動の決定論生成・ミュート和トーン・紙の余白を残すクリスプな作図で、③の思想は共通。この中から"③の中の本命の構成"を絞り込みます。

同じ6冊を各文法で描くので横比較できます。🎲 別の蔵書で6冊入替（各表紙はタイトル由来＝同じ本は常に同じ絵）。◐ ライト/ダークで全機反転。Ⓐ〜Ⓕは全て③の下位文法です。
本命の文法・混ぜたい要素を教えてください（例「Ⓒ弧を基調に、たまにⒶの一手」「Ⓕ円相をもっと大きく」）。
次の一手：この6文法から③の最終構成を確定（複数の混成も可）。決まったら色域・線幅・余白量・ライト/ダークの塩梅を詰め → Compose（GridBookCard／BookCard.kt）へ翻訳。
実装は title.hashCode()→Random(seed) の Canvas 作図（drawCircle/drawArc/drawLine/drawRect と塗り分けのみ＝画像を持たず容量ゼロ・にじみblur不要で最も軽い）。
