trailing 現在値を落とすと 2026-08-06 案C 裁定を部分的に取り消すことになる

案C（節ラベル trailing に現在値）は「単独チップでは状態が読めない」ことへの手当てだった。 2択タグにするとタグ自身が現在値を語るので二重になる。落とすのが素直だが、 残す亜種（本文の向き ……… 横書き ＋ 2択タグ）も選べる——その場合は 「文字サイズ 18sp」「本文余白 20dp」と同じtrailing に現在値を出す節の並びが揃う利点がある。 どちらにするかも同時に裁定してほしい（この頁の絵は落とした形）。

覆すなら記録を書き換える（消さない）

settings-D.html:97-101 には「不採用・案B 二択チップ化（2026-08-06 裁定）」が理由つきで残っている。 採用に倒れたらその記述を消さず、「2026-09-03 に実使用の報せ〈オンオフに見える〉で覆した／ 理由②はテーマ節の先例で弱いと判断」へ書き換える。消すと、次に誰かが同じ案を出したとき 「一度どう転んだか」が失われる（CLAUDE.md「採らなかった案は git log に記録されない」）。
