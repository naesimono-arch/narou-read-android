作品詳細 — 題名の箱（maxLines=2 が一度も成立していない件）

赤い破線が題名の箱の実寸。箱は dp 固定で、入りきらない行は描かれずに消える（clip ではなく行落ち）。 各列は題名の長さ（52字 / 25字 / 8字）。

⚠️ どの案でもあらすじは1行も減らない。書影ブロック高 = max(帯, 164) + 2 で、 書影カード下端 164dp が既に支配的だから。動くのは書影カードが帯を越える幅（正本が「面の上に置かれた本」の要と書いた 44dp）だけ。

§1 fontScale 1.0 — 箱をどうするか

現状の 44dp は「2行ぶん」のつもりで置かれた値だが、自然行高 22.75×2 = 45.5dp に 1.5dp 足りない。 下の3案は「不足を埋める」「1行と決める」「字を落として収める」の3方向。

§2 fontScale 2.0 — 題名の箱の裁定だけでは 2.0 は解けない

左2枚＝帯が dp 固定のまま（現行）。箱も固定なのでどの案でも1行で、作者とジャンルは箱から溢れて判読不能のまま。 右2枚＝帯を fontScale 追従にした場合（版面比較モックの案A）。作者とジャンルは読めるようになるが、 題名の2行目は現状の箱のままでは 2.0 でも出ない——不足は 1.5dp という「量」ではなく 箱 44 ÷ 行 45.5 = 0.967 という「比」なので、箱ごと拡大しても比は変わらないから。 つまり 2行を出したいなら §1 の T2／T3（比を直す）が必須で、案A は作者・チップの可読を直すだけ。 逆に §1 だけ直しても 2.0 の作者・チップは切れたまま＝2つの裁定は独立ではなく、噛み合わせて初めて 2.0 が成立する。
