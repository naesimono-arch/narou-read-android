実装への申し送り（裁定後・第2稿⑦の増分のみ）: ①動くのは高負荷 ON のときだけ・通常モード完全静止・reduce-motion 完全静止・Web未取込対象外・ tip2 のみ棒連動——いずれも第2稿と同一。 ②非 transform の写し先も第2稿⑦と同一経路（stroke-width→Stroke(width)／opacity→Color.copy(alpha)／ stroke-dashoffset→PathEffect.dashPathEffect／brightness・saturate→HSL で色を直接計算）。 ③派手版の増分＝drop-shadow のグロー: Canvas に等価物が無いため、 同グリフを band 色半透明で BlurMaskFilter（native Paint）を掛けて前描きする2パス描画で同じ見えを作る。 ぼかし半径は CSS の calc(var(--gs)×px) と同じくマウント倍率を掛ける（実寸で過大・拡大で過小を防ぐ）。 ④skewX（tip3）は DrawScope の withTransform＋Matrix skew で等価＝近似ではない。 ⑤光を持つのは tip0/tip5 の2種だけ＝全種グロー化は画一化のため実装でも広げない。
