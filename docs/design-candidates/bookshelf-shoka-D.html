固定の6型を手で割り当てるのではなく、タイトルをシードに滲みプリミティブを動的に組み合わせて、作品ごとに一意の滲みを自動生成します。同じ作品は常に同じ滲み／違う作品は必ず違う滲み（決定論的）。骨格＝AB3は据え置き。左＝ライト／右＝ダーク。

材料（墨の型）を15種に拡張＝円相・塊・飛沫・霞・遠山・たらし込み・三日月・勾玉・波紋・点群・双つ玉・墨溜まり・扇・走り・かすれ雲。各作品で種から2〜3個を選び、位置・向き・大きさ・色を決めて重ねます（＝端正な型の組み合わせなので汚れず、材料が多い分 既視感が出にくい）。可読性のため題字帯（右）は避け濃度に上限。下のボタンで別の蔵書に差し替え＝各滲みはタイトル由来（同じ本は同じ絵）。

仕組み：① title → ハッシュ → 種　② 種の疑似乱数で 15種の墨の型から2〜3個を選び、各々の位置・向き（回転）・大きさ・色（＝和トーンに彩度/明度固定で色相のみ可変）を決めて重ねる　③ CSS blur（ダークは screen）で滲ませ、可読性のため題字帯を避け濃度に上限。型（材料）を増やすほど組み合わせが増え、既視感が減ります。
Compose 移植：title.hashCode() を種に kotlin.random.Random(seed)、Canvas の drawPath/drawCircle で同じプリミティブを描き、Modifier.blur() でにじませれば同一挙動になります（画像を持たずコードで生成＝容量ゼロ・無限バリエ）。
動的にじみ生成＝実装可能（このデモが実証）。骨格AB3・目録との足並みは維持、表紙だけタイトル駆動で自動生成。
次の一手：この「材料を組み合わせる」方式で確定なら Compose（GridBookCard）へ翻訳します。調整可＝材料の追加/取捨（さらに型を増やす・特定の型だけに絞る・気に入らない型を外す）、選ぶ個数（2〜3／常に2で静かに）、濃度、色域（全色相の低彩度／“藍・青磁・臙脂の和色だけ”に制限）、ライト/ダーク。
