了スタンプ押下アニメ（案A 確定） ／ 読了の瞬間（reachedEnd false→true）に書影左下の朱印「了」を押印。カバーは正本の canvas 生成栞エンジンをそのまま流用（近似CSSを廃止）。左上の1冊が対象。

試す＝「押印を再生」。A 判子プレスと即時(現状)を切替えて実栞上で確認。実装は 初回一回きり（既読了の再描画では出さない）。

§C 静謐・禁止則③ との整合（正当化の骨子）
朱印は装飾でなく「読了という状態変化の伝達」＝motion の許容目的。禁止則③が禁じる overshoot/bounce/spring 振動は、案Aが scale を 1.0 未満へ揺り戻さない単調ダウンで回避（1.2→1.0 で止まり跳ねない）。回転も -7°→0° の単調 settle。初回一回きり・自動ループ無し。→ §C の「静かな伝達」に収まる。
実装メモ（裁定後）
Motion トークン（theme/Motion.kt）へ MotionDurationSeal(220) / MotionEasingSeal 相当を新設し BookCard.kt の isFinished seal に付与。トリガは reachedEnd の false→true 遷移のみ（既読了の再描画では出さない＝remember でラッチ）。§C 改訂（押印を許容例として明記）は ADR0014 追補で記録。質感の最終確定は実機後詰め（ADR0005-B）。
