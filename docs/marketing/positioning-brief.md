# 小説リーダー — 戦略メモ（簡易版）

> 広報／マーケの**方向性づけ**のためのざっくり資料。細部は詰めない。
> 詳しい版（メッセージング・ストア文案・トーン等）は別途アーティファクトあり。

## これは何か

なろう系Web小説を**静かに読む**ためのAndroidアプリ。
手元の小説PDFを **ふりがな付き・縦書き** で美しく描画する、パーソナル読書アプリ。
（＝単なるPDFビューアではなく「読書体験」がプロダクト）

## 誰のため

- なろう系を日常的に読む人（特に公式の縦書きPDFを手元で読みたい層）
- 広告・トラッキング・肥大アプリにうんざりしている「静かに読みたい」層
- 読書環境の見た目にこだわる人（着せ替え好き）

## ウリ（3つ）

1. **競合に無い読書体験** — PDF→ふりがな縦組みをネイティブ描画（他はビューア止まり／WebView頼み）
2. **静けさ＝設計** — 完全ローカル・約8MB・権限最小・トラッキングなし
3. **着せ替え（装いの間）** — 色替えでなく体験ごと切り替わるスキン
   ⚠️ **初回リリースでは訴求に使えない**（2026-08-06 確認）: `SKIN_SWITCHING_ENABLED` が release で false＝
   `Features.skinSwitchingEnabled`（`build.gradle:153`）。ADR 0027 のとおり課金実装後のアップデート目玉として
   温存する方針なので、**初回のストア説明文からは外す**こと。解禁便でここを復活させる。
   代替の3つ目の柱＝下記「主な機能」の Web 取込（カクヨム・暁）＝**オフラインで読める蔵書が増える**話。

## 主な機能

- ふりがな（ルビ）付き読書／縦書き表示
- 没入モード（タップでUIが消える）＋スワイプ章送り
- 読書位置・読了の自動記録（続きから再開）
- なろう発見・検索（ランキング／ジャンル／キーワード）※本文は取得せず公式へ送客
- **Web 取込（カクヨム・暁）** — 手元の蔵書としてオフラインで読める（`SiteAdapterRegistry` が対応可否を判定し、
  規約で禁止のサイトは除外・公式ページ直行の逃げ道つき。2026-08-06 時点で稼働中の対応先はこの2つ）
- 新着通知（既定オフ・オプトイン）
- 自動バックアップ（蔵書・読書位置・設定）／本棚（栞書影・フィルタ・並べ替え）

## ポジション（競合との違い）

一般的ななろう系アプリ ＝ 広告主体・数十MB・単一UI・ビューア頼み。
本アプリ ＝ **広告に頼らない・軽い・着せ替え・ふりがな縦組みの描画品質**で差別化。

## 収益／広告の方針

- **基本ゼロ**。現状は広告なし・計測なしの完全ローカル。
- 将来的にいずれか導入を検討（＝「静けさ」を壊さない控えめな形が前提）。
- そのため訴求では「一切ない／永久無料」と**言い切らない**（"広告に頼らない・静かな"に留める）。

## 言わない方がいいこと（安全弁）

- ✕「なろうの本文が読める／DLできる」— 本文は取得しない。読むのは利用者のPDF、発見は公式へ送客のみ。
- ✕ 公式／なろう公認と誤認させる表現（非公式の個人開発）
- ✕ 開発中スキンを"今ある"扱い（訴求は出荷済みのものに限定）
- ✕ クラウド／アカウント同期（無い。バックアップは端末ローカル）
