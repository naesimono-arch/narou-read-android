# 小説リーダー — 戦略メモ（簡易版）

> 広報／マーケの**方向性づけ**のためのざっくり資料。細部は詰めない。
> 詳しい版（メッセージング・ストア文案・トーン等）は別途アーティファクトあり。

## これは何か

なろう系Web小説を**静かに読む**ためのAndroidアプリ。
手元の小説PDFを **ふりがな付き・縦書き** で美しく描画する、パーソナル読書アプリ。
（＝単なるPDFビューアではなく「読書体験」がプロダクト）

## 誰のため

- なろう系を日常的に読む人（特に公式の縦書きPDFを手元で読みたい層）
- 広告・トラッキング・肥大アプリにうんざりしている「静かに読みたい」層
- ⚠️ **「着せ替え好き」は初回リリースの狙いから外す**（2026-08-17 裁定）。スキン M/P/J は ADR 0027 で release 非搭載＝
  `SKIN_SWITCHING_ENABLED=false`（`android/app/build.gradle:153`）→ `Features.skinSwitchingEnabled`（`Features.kt:29`）→
  設定の**きせかえ行ごと不可視**（`ui/skins/k/SettingsScreenK.kt:155`）＋装いの間はルート未登録（`MainActivity.kt:314`）。
  **捨てたのではない＝解禁便（課金アップデート便＝ADR 0027 の解凍条件）で狙う層**として温存する。そこでこの行を戻す。

## ウリ（3つ）

1. **競合に無い読書体験** — PDF→ふりがな縦組みをネイティブ描画（競合5本のうち PDF を扱う B も「取り込んだPDFを開く素のビューア」でルビ・縦組み変換はしない＝`docs/reference/04-competitor-app-features.md` §5-3）
   ⚠️ **「他はビューア止まり／WebView頼み」と一般化しない**（2026-08-17 突合）: なろう本文を WebView 丸表示するのは A・C で、
   B は他サイトのHTMLから自前の縦書き描画をし、E（カクヨム公式）は自社BEからネイティブ描画する。差別化が立つのは**PDF を素材にする経路**に限る。
2. **静けさ＝設計** — 自前サーバーなし（広告SDK・解析SDKともにゼロ）・**ダウンロード約8.4MB**・権限最小・トラッキングなし
   ⚠️ **サイズは「何を測った値か」を必ず添える**（2026-08-17 再測・内訳は下の「自アプリの実測」）: 8.4MB＝
   **Play が配信する圧縮後のダウンロードサイズ**（8,356,913 バイト）。端末上に置かれる実ファイル合計は **11.1MB**、
   universal APK 単体なら 8.7MB。**競合と並べるときは「端末上の実ファイル合計」どうし**（下の競合表・同一基準である根拠は同表の前書き）＝
   **数値だけを裸で出さず「ダウンロード」か「端末上」かを明記する**。
   ⚠️ **「完全ローカル」と言い切らない**（2026-08-17 突合）: ①端末の自動バックアップが有効なら蔵書リスト・読書位置・設定は
   利用者の Google ドライブへ載る（`android/app/src/main/res/xml/data_extraction_rules.xml` の `<cloud-backup>`）
   ②なろう公式API・カクヨム/暁の取込・Play の評価打診で通信はする。言えるのは「利用者を追跡しない・自前サーバーを持たない」まで。
3. **着せ替え（装いの間）** — 色替えでなく体験ごと切り替わるスキン
   ⚠️ **初回リリースでは訴求に使えない**（2026-08-06 確認・**2026-08-17 裁定で「解禁便まで伏せる」に確定**）:
   `SKIN_SWITCHING_ENABLED` が release で false＝`Features.skinSwitchingEnabled`（`build.gradle:153`）。ADR 0027 のとおり
   課金実装後のアップデート目玉として温存する方針なので、**初回のストア説明文からは外す**こと。解禁便でここを復活させる。
   代替の3つ目の柱＝下記「主な機能」の Web 取込（カクヨム・暁）＝**オフラインで読める蔵書が増える**話。

## 主な機能

- ふりがな（ルビ）付き読書／縦書き表示
- 没入モード（タップでUIが消える）＋スワイプ章送り
- 読書位置・読了の自動記録（続きから再開）
- なろう発見・検索（ランキング／ジャンル／キーワード）※本文は取得せず公式へ送客
- **Web 取込（カクヨム・暁）** — 手元の蔵書としてオフラインで読める（`SiteAdapterRegistry` が対応可否を判定し、
  規約で禁止のサイトは除外・公式ページ直行の逃げ道つき。2026-08-06 時点で稼働中の対応先はこの2つ）
- 新着通知（既定オフ・オプトイン）
- 自動バックアップ（**蔵書リスト**・読書位置・設定＝Android 標準の自動バックアップ。**本文の実体は対象外**で、
  復元後は再取込が要る〔読書位置は保持〕＝ADR 0015・`res/xml/backup_rules.xml`。「蔵書がまるごと戻る」とは書かない）
- 本棚（栞書影・状態フィルタ〔すべて／よみかけ／未読／読了〕・**続きを読む本が上に来る自動並び**）
  ⚠️ **利用者が選ぶ「並べ替え」UI は無い**（ADR 0016 で「ユーザー選択式ソート UI の先行追加」を却下済み。訴求語に使わない）

## ポジション（競合との違い）

一般的ななろう系アプリ ＝ 広告主体・**十数〜60MB**・単一UI・ビューア頼み。
本アプリ ＝ **広告に頼らない・軽い・ふりがな縦組みの描画品質**で差別化。

## 収益／広告の方針

- **基本ゼロ**。現状は広告SDK・解析SDKともに1つも入っていない（端末内診断は外部送信ゼロ）。
  ただし「完全ローカル」とは書かない（理由＝ウリ2の注記）。
- 将来的にいずれか導入を検討（＝「静けさ」を壊さない控えめな形が前提）。
- そのため訴求では「一切ない／永久無料」と**言い切らない**（"広告に頼らない・静かな"に留める）。

## 言わない方がいいこと（安全弁）

- ✕「なろうの本文をアプリが取ってくる／スクレイプする」— なろう本文は**機械取得しない**。なろうは①発見・検索が公式APIのメタのみ
  ②閲覧は公式へ送客 ③蔵書化は**公式の縦書きPDF機能を、広告込みの公式ページ上で利用者自身がDLボタンを押して**行う（ADR 0011・
  `ui/discovery/PdfImportScreen.kt`。一括DL・自動DLは実装しない守り）。
  ⚠️ 旧記載「本文は取得しない／読むのは利用者のPDF」は**実装と食い違うので使わない**（2026-08-17 突合）＝
  カクヨム・暁は本文HTMLを取り込むし、なろうPDFもアプリ内WebView経由でDLされる。線引きは「取得しない」ではなく
  「**なろう本文の機械取得はしない／公式の導線と広告を素通りしない**」。
- ✕ 公式／なろう公認と誤認させる表現（非公式の個人開発）
- ✕ 開発中スキンを"今ある"扱い（訴求は出荷済みのものに限定）
- ✕ **アプリ独自の**クラウド／アカウント同期（無い＝ログインもサーバーも持たない）。
  ⚠️ 旧記載「バックアップは端末ローカル」は**誤り**（2026-08-17 突合）＝`<cloud-backup>` を include しており、
  Android 標準の自動バックアップで利用者の Google ドライブへ載る。言えるのは「**同期用のアカウント登録は要らない**」まで。
