# なろう小説API 利用マニュアル

## 1. 概要
なろう小説APIでは、小説家になろうに掲載されている作品情報を取得できます。

- 対象外: R18作品はこのAPIでは取得できません（別途「なろうR18小説API」が存在します）。
- 応答形式: HTTPリクエストに対し、JSON形式、JSONP形式、YAML形式、PHPのserializeで応答します。
- 遅延: 実際の作品データが修正されてからAPIに反映されるまで、平均5分程度（最大2時間）の誤差があります。
- 必要技術: 利用にはJavaScript、Perl、PHP、Ruby、Java、C言語などでのプログラミングが必要です。
- 文字コード: APIサーバが出力する文字コードはすべてUTF-8です。

---

## 2. APIのURLと基本仕様
https://api.syosetu.com/novelapi/api/

- GETメソッドで送信してください（POSTでは受信不可）。
- 日本語などのマルチバイト文字を送信する際は、文字コードをUTF-8にし、URLエンコードを行う必要があります。

## 3. 出力形式と基本パラメータ

### 3.1 出力形式（outパラメータ）
デフォルトの出力形式はYAMLですが、out`パラメータを指定することで変更可能です。

- yaml : YAML形式（デフォルト）
- json : JSON形式
- php : PHPのserialize()
- atom : Atomフィード
- jsonp : JSONP形式

JSONPのコールバック指定
JSONP形式を利用する場合、callbackパラメータで関数名を指定します（半角英数字など ^$?[a-zA-Z0-9\[\]\.\_]+$ の正規表現に一致するもの）。
例: ?out=jsonp&callback=call

### 3.2 出力GETパラメータ一覧

| パラメータ | 値 | 説明 |
| --- | --- | --- |
| gzip | int(1〜5) | gzip圧縮して返します。1〜5で圧縮レベルを指定。転送量上限を削減するため推奨。 |
| out | string | 出力形式を指定（上記参照）。 |
| of | string | 出力項目を個別に指定。複数項目はハイフン(-)で区切る。転送量軽減のため推奨。未指定時は全項目出力。 |
| lim | int(1〜500) | 最大出力数を指定。最低1、最高500。未指定時は20件。 |
| st | int(1〜2000) | 表示開始位置の指定。3作品目以降なら3と指定。 |
| order | string | 出力順序を指定。未指定時は新着更新順。 |

orderパラメータの指定可能値
- new : 新着更新順
- favnovelcnt : ブックマーク数の多い順
- reviewcnt : レビュー数の多い順
- hyoka : 総合ポイントの高い順
- hyokaasc : 総合ポイントの低い順
- dailypoint : 日間ポイントの高い順
- weeklypoint : 週間ポイントの高い順
- monthlypoint : 月間ポイントの高い順
- quarterpoint : 四半期ポイントの高い順
- yearlypoint : 年間ポイントの高い順
- impressioncnt : 感想の多い順
- hyokacnt : 評価者数の多い順
- hyokacntasc : 評価者数の少ない順
- weekly : 週間ユニークユーザの多い順（前週日曜〜土曜分、毎週火曜早朝リセット）
- lengthdesc : 作品本文の文字数が多い順
- lengthasc : 作品本文の文字数が少ない順
- generalfirstup: 初回掲載順
- ncodeasc : Nコード昇順
- ncodedesc : Nコード降順
- old : 更新が古い順

### 3.3 特殊な出力設定パラメータ
YAML形式のライブラリ指定（libtype）
- 未指定または1以下 : 従来通りのライブラリ（数値構成の文字列はダブルクォートで囲まれない）
- 2以上 : 新ライブラリ（文字列と数値の型指定を厳格化、数値構成の文字列をダブルクォートで囲み、マルチバイト文字や制御文字をエスケープ処理）

Atomフィードの出力日付指定（updatetype）
- 未指定 : 作品の更新日時(novelupdated_at)を日付として出力
- 2 : 最終掲載日(general_lastup)を日付として出力

## 4. 条件抽出GETパラメータ

### 4.1 テキスト検索
| パラメータ | 値 | 説明 |
| --- | --- | --- |
| word | string | 単語検索。UTF-8でURLエンコード必須。スペース区切りでAND抽出。部分一致。 |
| notword | string | 除外単語。スペース区切りで複数指定可。部分一致で除外。 |

抽出対象の範囲指定
- title=1 : タイトルを抽出対象にする
- ex=1 : あらすじを抽出対象にする
- keyword=1 : キーワードを抽出対象にする
- wname=1 : 作者名を抽出対象にする
※上記4項目をすべて指定しない場合は全項目が対象。wordがNコードと判断された場合は全抽出対象を無視し、Nコード検索となります。

### 4.2 ジャンル指定・除外
ハイフン(-)で区切ることで複数の一括抽出や除外が可能です。

大ジャンル（biggenre / notbiggenre）
0:未選択 / 1:恋愛 / 2:ファンタジー / 3:文芸 / 4:SF / 99:その他 / 98:ノンジャンル

ジャンル（genre / notgenre）
- 未選択 : 0
- 恋愛 : 101(異世界), 102(現実世界)
- ファンタジー : 201(ハイ), 202(ロー)
- 文芸 : 301(純文学), 302(ヒューマンドラマ), 303(歴史), 304(推理), 305(ホラー), 306(アクション), 307(コメディー)
- SF : 401(VRゲーム), 402(宇宙), 403(空想科学), 404(パニック)
- その他 : 9901(童話), 9902(詩), 9903(エッセイ), 9904(リプレイ), 9999(その他)
- ノンジャンル : 9801

### 4.3 要素・属性の指定と除外
値に 1 を指定して抽出・除外を行います。

| 抽出指定 | 除外指定 | 要素名 |
| --- | --- | --- |
| isr15 | notr15 | R15 |
| isbl | notbl | ボーイズラブ |
| isgl | notgl | ガールズラブ |
| iszankoku | notzankoku | 残酷な描写あり |
| istensei | nottensei | 異世界転生 |
| istenni | nottenni | 異世界転移 |
| istt | - | 異世界転生 または 異世界転移（抽出のみ） |

### 4.4 範囲指定と特定条件による抽出
範囲指定を行う場合は、数値をハイフン(-)で区切ります。

| パラメータ | 説明 | 指定方法の例 |
| --- | --- | --- |
| length | 文字数 | 1000-2000, 1000- (以上), -2000 (以下) |
| minlen / maxlen | 最小文字数 / 最大文字数 | ※lengthとの併用不可 |
| time | 読了時間（分） | 30-100 ※読了時間＝文字数÷500(切り上げ) |
| mintime / maxtime | 最小読了時間 / 最大読了時間 | ※timeや文字数指定と併用不可 |
| kaiwaritu | 会話率(%) | 10-50, 50-, 30 |
| sasie | 挿絵の数 | 1-5, 1-, 3 |
| ncode | Nコード | ハイフン区切りでOR検索可（検索除外設定作品は取得不可） |
| userid | ユーザID | ハイフン区切りでOR検索可 |

### 4.5 その他のステータス・日時指定
| パラメータ | 値 | 説明 |
| --- | --- | --- |
| type | string | t:短編, r:連載中, er:完結済連載, re:全連載, ter:短編と完結済連載 |
| buntai | int/string | 1:字下げなし連続改行多, 2:字下げなし改行平均, 4:字下げ適切連続改行多, 6:字下げ適切改行平均（試験提供機能。ハイフンでOR検索可） |
| stop | int | 1:長期連載停止中を除外, 2:長期連載停止中のみ取得（※最終掲載日から63日以上経過した未完結連載作品） |
| ispickup | int | 1:小説ピックアップ対象作品のみ抽出 |

日時による抽出（lastup: 最終掲載日 / lastupdate: 最終更新日）
以下の文字列、またはUNIXタイムスタンプのハイフン区切り（開始-終了）で指定します。
- thisweek : 今週（日曜0時開始）
- lastweek : 先週
- sevenday : 過去7日間
- thismonth : 今月
- lastmonth : 先月

## 5. 出力項目（レスポンス内容）
最初の要素には「全作品出力数（allcount）」が入り、以降は1作品ごとの情報が配列等で入ります。
（※allcountは、1000作品以上の場合、最長で4時間遅れの情報となる場合があります）

ofパラメータに略称（ハイフン区切り）を指定することで、必要な項目のみを絞り込んで出力できます。

| 項目名 | of値 | 説明 |
| --- | --- | --- |
| title | t | 作品名 |
| ncode | n | Nコード |
| userid | u | 作者のユーザID(数値) |
| writer | w | 作者名 |
| story | s | 作品のあらすじ |
| biggenre | bg | 大ジャンル（数値） |
| genre | g | ジャンル（数値） |
| gensaku | - | 現在未使用項目（常に空文字列） |
| keyword | k | キーワード |
| general_firstup | gf | 初回掲載日（YYYY-MM-DD HH:MM:SS） |
| general_lastup | gl | 最終掲載日（連載時の次話投稿時にも反映される。編集時は反映不可） |
| novel_type | nt | 1:連載, 2:短編（※of指定時はnoveltypeとして出力されるため注意） |
| end | e | 0:短編・完結済, 1:連載中 |
| general_all_no | ga | 全掲載エピソード数（短編の場合は1） |
| length | l | 作品文字数（スペース、改行、一部タグなどを除外した実質文字数） |
| time | ti | 読了時間（分単位） |
| isstop | i | 1:長期連載停止中, 0:それ以外 |
| isr15 | ir | 1:R15要素あり, 0:なし |
| isbl | ibl | 1:ボーイズラブ要素あり, 0:なし |
| isgl | igl | 1:ガールズラブ要素あり, 0:なし |
| iszankoku | izk | 1:残酷な描写あり, 0:なし |
| istensei | its | 1:異世界転生要素あり, 0:なし |
| istenni | iti | 1:異世界転移要素あり, 0:なし |
| global_point | gp | 総合評価ポイント（ブックマーク数×2 ＋ 評価ポイント） |
| daily_point | dp | 日間ポイント（過去24時間以内の新規登録分） |
| weekly_point | wp | 週間ポイント（過去7日以内の新規登録分） |
| monthly_point | mp | 月間ポイント（過去30日以内の新規登録分） |

| fav_novel_cnt | f | ブックマーク数 |
| impression_cnt | imp | 感想数 |
| review_cnt | r | レビュー数 |
| all_point | a | 評価ポイント |
| all_hyoka_cnt | ah | 評価者数 |
| sasie_cnt | sa | 挿絵の数 |
| kaiwaritu | ka | 会話率 |
| novelupdated_at | nu | 作品の更新日時（最後に作品データが更新された時刻） |
| updated_at | ua | データ更新日時（システム用。総合ポイント変更時などにも反映される） |

### 5.1 オプション項目（opt）
opt=weekly を指定すると、週間ユニークユーザ数（項目名: weekly_unique）が追加されます。前週の日曜から土曜分の合計で、毎週火曜早朝に更新されます。

### 5.2 Atomフィードの特例
out=atomを指定した場合のみ出力制限があり、「タイトル、URL、あらすじ、初回掲載日、最終掲載日」のみが出力されます（評価ポイントやキーワードなどは出力されません）。

## 6. 利用制限と遅延に関する注意

### 6.1 利用制限（※現在は休止中）
負荷状況により今後導入される可能性があるため、キャッシュの導入など制限を想定した設計が推奨されています（キャッシュは最長でも2週間以内で更新・削除を行うこと）。

- IPアドレスごとに利用制限を実施。
- 1日の上限：80,000リクエスト または 転送量上限400MByte。
- 初回アクセスから24時間後にカウンタと初回アクセス時刻をリセット。
- リクエスト回数または転送量が上限の120%を超えると、ほとんど接続できなくなります。

転送量制限の回避方法
1. gzip=5 を指定し、圧縮ファイルで受信する。
2. データ容量が最も小さい YAML形式 を使う。
3. ofパラメータ を使い、必要な項目のみを出力する。

### 6.2 遅延について
APIは分散されたスレーブサーバに接続されるため、以下の遅延が発生する可能性があります。

- ネットワーク障害時、サーバ間でデータにばらつきが生じることがある。
- 作品データの修正からAPIへの反映まで 平均5分程度（最大2時間） の誤差がある。
- キャッシュの都合上、以下の項目はさらに 15分〜2時間 の遅れが発生する。
  - stop, global_point, fav_novel_cnt, review_cnt, all_point, all_hyoka_cnt
