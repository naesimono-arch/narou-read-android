# 02 なろう小説API — アプリ視点ダイジェスト

> **完全なリファレンスの正本 = `docs/reference/narou_api_manual.md`（同フォルダ）。**
> ここはそこから「このアプリの機能検討に効く要点」だけを抜いたもの。数値・全パラメータは正本を見る。

## エンドポイント / 基本

- `https://api.syosetu.com/novelapi/api/` — **GET のみ**（POST不可）。
- 応答形式: YAML(既定) / **JSON** / JSONP / Atom / PHP-serialize。→ アプリからは `out=json` 一択。
- 文字コード: **UTF-8**。マルチバイトのクエリ（`word` など）はURLエンコード必須。
- R18作品は対象外（別途「なろうR18小説API」）。
- 反映遅延: 作品修正→API反映まで平均5分・最大2時間。一部項目（ポイント/ブックマーク数等）はさらに15分〜2時間遅延。

## ⚠️ 最重要 — このAPIは「メタデータ専用」

**返るのは作品の情報だけ。本文（エピソード本文テキスト）は一切返らない。**

返る主な項目（`of` で絞り込み可）:

| 用途 | 項目（of値） |
|---|---|
| 識別 | `ncode`(n) Nコード / `title`(t) / `writer`(w) 作者名 / `userid`(u) |
| 内容説明 | `story`(s) あらすじ / `keyword`(k) / `biggenre`(bg)・`genre`(g) ジャンル |
| 規模 | `length`(l) 文字数 / `time`(ti) 読了時間 / `general_all_no`(ga) 話数 / `end`(e) 完結フラグ |
| 人気/ランキング | `global_point`(gp) 総合 / `daily/weekly/monthly/quarter/yearly_point` / `fav_novel_cnt`(f) ブックマーク数 / `review_cnt`(r) / `all_hyoka_cnt`(ah) |
| 日時 | `general_lastup`(gl) 最終掲載 / `novelupdated_at`(nu) 更新 |

→ **本文を読むには別経路が要る**（`03` の設計オプション参照）。API単独で完結するのは「一覧・検索・ランキング・作品情報カード」まで。

## アプリで効く検索/絞り込みパラメータ

| パラメータ | 使いどころ |
|---|---|
| `order` | ランキング切替の中核。`hyoka`(総合) / `daily_point` / `weekly` / `favnovelcnt`(ブックマーク) / `new`(新着) / `quarterpoint` 等 |
| `word` / `notword` | フリーワード検索（AND・部分一致）。`title=1`/`ex=1`/`keyword=1`/`wname=1` で対象範囲指定 |
| `ncode` | Nコード直接指定（既にNコードを知っている作品の情報取得。ハイフンでOR） |
| `biggenre` / `genre` | ジャンル絞り込み（1:恋愛 2:ファンタジー 3:文芸 4:SF 99:その他 98:ノンジャンル …） |
| `type` | `t`短編 / `r`連載中 / `er`完結済連載 / `re`全連載 / `ter`短編＋完結済 |
| `istensei`/`istenni`/`istt` | 異世界転生/転移で絞る（なろう系の定番導線） |
| `length` / `time` | 文字数・読了時間レンジ（「サクッと読める短編」等の導線に） |
| `lim`(1-500) / `st`(1-2000) | ページング。既定 `lim=20` |

## 転送量を抑える作法（マニュアル §6 準拠）

現在レート制限は休止中だが「導入され得る前提で設計せよ」が公式スタンス。最初からケチる:

1. `gzip=5`（圧縮受信）
2. `out=json`（アプリで扱いやすく、YAMLより実装容易。※容量最小はYAMLだが実装コストとトレードオフ）
3. `of=` で**必要項目だけ**取得（一覧カードに要るのは t/n/w/s/gp/ga/e 程度）
4. **キャッシュ必須**（公式推奨: 最長でも2週間で更新/削除）。ランキングは分単位で変わらないので端末キャッシュが効く。

### 一覧取得のリクエスト例（イメージ）

```
GET https://api.syosetu.com/novelapi/api/
      ?out=json&gzip=5
      &order=weekly                 # 週間ランキング
      &of=t-n-w-s-gp-ga-e-l         # カード表示に要る項目だけ
      &lim=30                        # 30件
```

## 法務/規約メモ（検討時に必ず意識）

- **メタデータ利用**: 本APIの範囲内なら明快。R18は別API・要確認。
- **本文取得は別問題**: 本文の公式APIは無く、取得するなら `ncode.syosetu.com/{ncode}/{話数}/` の**HTMLを取得してパース**することになる（＝スクレイピング）。利用規約・robots・サーバ負荷配慮・再配布可否が絡む**別レイヤの判断**。安易に前提化しない。→ `03` で明示的な未決事項として扱う。
