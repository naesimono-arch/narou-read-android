# Web小説サイト 実地照合の結果（対応候補の生存・規約・構造）

2026-07-23 の Web 一次ソース照合で集めた**事実**の置き場（handover から移設）。
**裁定の正本は ADR 0024（追記含む）**——ここは「どのサイトが生きていて、規約・robots・HTML 構造がどうだったか」だけを持つ。
対応面の拡大は 2026-07-23 にいったん打ち止めと裁定済みなので、**再開・再裁定するときに最初に開く表**として使う。

## 着手済み・対応中

- **暁（akatsuki-novels.com）**: 生存・**SSR 静的**・robots 実質無制限・規約に自動取得/私的複製の禁止明文なし（著作権法の再掲のみ）。
  ADR 0024 の「着手時個別照合」を満たすため裁定不要で着手 → 表駆動（`scrape/generic/` の SiteProfile）で着地済み。
- **カクヨム**: JSON 系＝専用アダプタで着地済み。

## Blocked 判定（規約の包括禁止条項・保守読み）

- **野いちご／ベリーズカフェ**: 両者とも第5条に「（サービス内容の）複製・公開・送信…転載・再利用しないことに同意」の**包括禁止の明文**があり、
  端末内保存が「複製」に直接該当する。**robots は Allow だが規約優先**の保守判定。
  前文の「個人的使用の為に提供」との緊張＝私的複製抗弁は法解釈依存のため、最終扱いはアルファポリスと同じ**まとめ裁定**へ合流させた。
- アルファポリス／Pixiv／なろうグループ: 判定と理由は ADR 0024 が正本（Pixiv は R-18 のログイン必須という技術コストの複合判断）。

## この照合から出た結論（2026-07-23）

**OK 側の「表駆動で足せる候補」は暁で打ち止め**。個人サイト系を拾う実質手段は汎用ヒューリスティック（G2）だけになるが、
G2 は「キリがない」として**不採用裁定**。将来の解放条件＝ハーメルン裁定 or グレー勢の再裁定 or 新規 SSR サイトの発見
