# エミュの `screenrecord` は使える。ただし 16ms 窓ではない

**いつ開くか**: 動きの検分（骨・残像・Predictive Back・フェードの出没）を機械で捉えたいとき。
または adb の合成入力で操作したのに画面が動かないとき。

## 1. `screenrecord` は AOSP エミュで使える（ColorOS では使えなかった）

実機 OPPO/ColorOS では `screenrecord` が塞がれており、「16ms 窓の標本化手段が無い＝骨・残像・
Predictive Back は肉眼判定しかない」と結論していた。**AOSP エミュでは動く**（アプリ描画も正しく入る）。
コマに割るのは `ffmpeg.exe` / `ffprobe.exe`（scoop shims・WSL interop で呼べる）。

## 2. ⚠️ ただし「録れなかった＝無い」とは言えない

出力は**変化があったときだけコマを吐く**＝等間隔ではない。実測のコマ間隔は **20〜63ms**（多くは 28〜50ms）、
静止中は **1.4〜3.1秒**空く。**60Hz の1〜2フレームだけ現れる現象は取りこぼしうる**。

- 使える: 数十 ms 以上続く現象（フェードの掛かり方・骨の差し替わり・シートの出方）を**コマで並べる**
- 使えない: 1〜2フレームのちらつき・1フレームだけの残像の**不在証明**

「録画に写っていないから起きていない」と書かない。写っていたことだけが証拠になる。

## 3. 合成入力が効かない場面がある（前提の問題ではなく入力手段の問題）

本棚の横スクロール行（`BookshelfK.kt` のフィルタチップ行）は**実装上スクロール可**なのに、
adb の合成入力では左端まで送れない——**横ドラッグをタブの `HorizontalPager` が必ず奪う**。
`input swipe` の尺を変える（400/1500ms）・`motionevent` を16手に小刻みにする・見切れたチップを直接タップ、
のいずれも失敗した。**実指で同じかは未確認**。

⚠️ ここを「前提が作れない」と誤診しない。前提（fontScale 2.0 でチップが溢れる状態）は作れていて、
**触る手段だけが無い**。同じ形の壁は、親が横ジェスチャを持つ面（タブ・ページャ）の中にある
横スクロール要素すべてで起こりうる。

## 4. 画面の回転は2つ揃えないと黙って無視される

`user_rotation` だけでは回らない。`accelerometer_rotation 0` と**両方**要る。
片方だけだとエラーも出ずに無視されるので「回したつもり」で撮ってしまう。

## 5. 「動いたか」は目視でなく**輝度の時系列**で決める（2026-09-02 追加）

コマを並べて眺めるだけでは「一瞬で消えた」以上のことが言えない。**対象が占める矩形の平均輝度を全コマぶん数値で出す**と、
中間値の有無で淡入淡出の有無が決まる:

```bash
ffmpeg.exe -i rec.mp4 -vf "crop=280:90:730:2000,signalstats,metadata=print:file=-" -f null - \
  | grep -E "pts_time|YAVG" | paste - -
```

実例（本棚K の拡張FAB・1080x2400）: 81＝FAB全開／147＝選択バー（FABなし）／230＝素の背景。
出没3経路（フィルタで `isEmptyShelf` を反転・選択モード出入り・取込開始）とも**中間輝度のコマが1枚も無い**
＝FAB は1コマで現れ1コマで消える。コード側も一致（`ui/skins/k/BookshelfK.kt` の FAB は素の `if` で `AnimatedVisibility` 無し）。
⚠️ §2 のとおり**逆向き（「無い」の証明）はできない**＝言えるのは「200ms 級の淡入淡出は無い」まで。

**蔵書0のまま FAB だけを出没させる手**（取込も削除も挟まず、画面で動くのが FAB だけになる）:
空棚でフィルタ「読了」を押すと `selectedStatus != null` で `isEmptyShelf` が false へ落ちる＝**蔵書0のまま FAB が出る**。
