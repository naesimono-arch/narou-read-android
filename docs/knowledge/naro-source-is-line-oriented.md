# なろう本文は行指向＝「行→段落結合」は原文に無い構造を作る操作

★★ / 2026-09-02 調査（独立再実装実験の裁定材料。**裁定は人間・未了**）

**1行要約**: web 原文の HTML は **原文1行 = `<p id="L…">` 1つ**（空行も `<br>` だけの `<p>` として実在）で、
サーバ側に「段落」という単位は無い。現行の抽出が行を段落へ結合しているのは、
データの復元ではなく**読み味のための意匠判断**にあたる。

## 世界の事実（web 原文の構造）

本文は `js-novel-text` / `p-novel__text` の直下に `<p id="L…">` が1行につき1つ並ぶ。空行も要素として実在する。
実測 1 話で 175 個の `<p>` を確認。第二実装の「原文の行をそのまま保持」がこの構造に一致する。

## 現行が失っている量（全話集計）

| 指標 | 現行 | 第二実装 | 現行の残存率 |
|---|---|---|---|
| 非空ユニット | 169,233 | 254,836 | 66.4%（**行境界の約1/3を結合で消失**） |
| 空行 | 69,309 | 141,042 | 49.1%（**約半分を喪失**） |

空行喪失は文書依存で、`N0833HI` は本文空行が 0 / 9,823 ＝全滅（既知の S3）。

## ⚠️ 「現行の段落誤り率」は厳密には計算できない（近似で埋めない）

依頼にあった現行側の誤り率は、**既存の突合成果物からは出せない**。
真因＝現行側ダンプはルビをインライン記法 `|親《読み》` で持っており、本文の装飾用 `《》` と機械的に分離できない。
このため flow が一致して比較可能になるのは 2,872 話中 **53 話（1.8%）**だけで、しかもその 53 話は
「ルビ・特殊字が少ない話」に偏る。偏り込みの参考値は行境界 4,840 本に対し誤分割 24 本（0.50%）・
意図的に消した境界 126 本（2.60%）だが、**偏りの補正はできていない**。
不足しているのは、ルビを構造フィールドで持つ現行側ダンプ（あれば全話を web と突合できる）。

## 裁定の論点（人間）

行→段落結合を**維持するなら**、原文に無い構造を作る意匠判断として明文化する。
**撤回するなら**、抽出は行保持にして結合は表示側へ移す。
判断材料が1つ足りない状態＝現行の誤り率は上記の理由で未測定のまま。
