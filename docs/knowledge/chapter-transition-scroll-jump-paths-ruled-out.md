# 「章遷移で描画が上部にジャンプする」— 調査済みで潰れた経路（同じ道を再探索しない）

実機のユーザー報告バグ。**報告者自身も再現できていない**ため、再現手順の取得が先決の状態が続いている
（取ってほしい条件＝`awaiting-human.md` の該当項目）。以下は**既に調べて否定した経路**の記録で、
次に着手する人が同じ探索を繰り返さないためのもの。

## 否定済み＝「本文で章遷移時にスクロールが 0 へリセットされる経路」は実コードに存在しない

1. **章→章は `AnimatedContent` が file でキーするため別サブコンポジション**＝`LazyListState` は毎回新規。
   **新章が先頭から始まるのは設計どおり**であって、症状とは別物。
2. **既読章へ戻る経路**は `sessionScrollByFile`→`chapterRestore`→(0,0) の順で復元される（0 固定ではない）。
3. **本文経路の明示スクロールは「最上部へ」ピルと a11y アクションだけ**で、いずれもユーザー操作起点。

## 別系統との切り分け

既知知見 `lazylist-loading-full-replace-scroll-reset.md` とは**別系統**
（本文の Loading は LazyColumn 自体が unmount されるため、あちらの機序はここに効かない）。

## 2026-08-05 の機械ハント（adb 総当たり）は空振り

何が足りずに判定不能で終わったか（①操作の実行検証 ②基準値の事前記録 ③軸の消化記録）と、
