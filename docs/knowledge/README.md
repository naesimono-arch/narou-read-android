# docs/knowledge — 外部事実の知見置き場（1知見=1ファイル）

旧 `task_diary.md`（凍結アーカイブ・既存 `#N` 参照は有効）の後継。
**外部プラットフォームの事実・落とし穴**（Android/OEM/Gradle/Room/Claude Code 等、コードと無関係に真で「はまったら引く」もの）を、**1知見=1ファイル**で置く。

## 書き方

- ファイル名: 内容が分かる短い kebab-case スラッグ（例: `coloros-fgs-timeout-kill.md`）。**連番は使わない**（並列レーン間の二重採番クラスを構造的に消すため）。
- 冒頭に: 重要度（★★★/★★/★）・日付・1行要約。本文は「症状 → 真因 → 対処 → なぜそうなるか」。
- 置き場の分担（旧 task_diary 凡例と同じ）: 実装パターン（コードが正本・why のみ）→ `docs/patterns/`／設計判断・Why-not → `docs/decisions/`（ADR）。
- 既存知見（task_diary #N・ここの既存ファイル）と重複するなら追記不要。既存 #N の増補が必要なときは task_diary 側を直接更新してよい（凍結は「新規エントリの追加停止」であって既存エントリの保守停止ではない）。
