# DropdownMenu が「ヘッダの途中」に開くのは offset のズレではなくアンカーの整列先

**重要度 ★★／2026-08-17 に真因確定（M 本棚で実機再現）／未修正＝直すかは裁定案件**

1行要約: **2行ヘッダの横に置いた ⋮ IconButton は1行目にしか整列しておらず、`DropdownMenu` はアンカー下端に開くので
メニュー上端がヘッダの途中（副題を横切る位置）に来る**＝副題の字面上部が帯状に露出する。

## 症状

本棚のアプリバー右の ⋮ を開くと、**メニュー面の上端に背後の文字が覗く**（メニューとバーの間に隙間があるように見える）。

## 再現手順（100% 再現）

設定 →きせかえ →**星図(M) を装着** →本棚タブ →アプリバー右の ⋮ (1280,272) をタップ。**ダーク・縦・グリッド面で100%**。

**症状の数値**: メニュー面の一様塗り (12,20,50) は **y=367** から始まり、それより上（y≈352–366・x≈110–500）に
ヘッダ副題「7冊 ・ 結ばれた星座 6 / 7」（bounds `[80,324][611,436]`）の字面上部が帯状に露出する。

## 真因

M のヘッダ（`SkyPlate`）は **`Row(verticalAlignment = Alignment.Top)`** の中に
〈`weight(1f)` の Column＝題字 y192-308 ＋ 副題 y324-436 の**2行**〉と〈アイコン群（一覧切替／装いの間／⋮）〉を並べている。
アイコンは **Top 整列＝1行目の高さしか占めない**ので、⋮ を包む `Box`（アンカー）の下端はヘッダ全体の下ではなく
**ヘッダの途中（y≈367）** にある。`DropdownMenu` は**アンカーの下端**に上端を合わせて開くため、
アンカー下端〜ヘッダ下端の帯（＝副題の上半分）がメニューの外に残って覗く。

該当箇所: グリッド面＝`android/app/src/main/java/com/novelreader/ui/skins/m/BookshelfSkyM.kt`（`SkyPlate` の
`Row(verticalAlignment = Alignment.Top)` 内・`Box { IconButton + DropdownMenu }`）／
一覧面＝同 `BookshelfLogM.kt:561-571`（`PlateIcon` 版だが構造は同型）。

## 対処

**アンカーの下端をヘッダ全体の下へ揃える**（⋮ を包む Box をヘッダ行の高さいっぱいに伸ばす等）。
offset を足して押し下げるのではない——押し下げは端末・インセット・フォントスケールごとに合わせ直しが必要な当て推量になる。

⚠️ **「Material3 の位置決め × edge-to-edge インセットの合成なのでコードからは導けない」という見立ては誤りだった**
（2026-08-17 以前の台帳記述）。導けなかったのは**アンカーの高さを見ていなかった**からで、
`DropdownMenu` の位置決め自体は素直にアンカー下端へ開いている。

## 一般化（次に踏む場所）

**複数行のヘッダの横にアイコンを Top 整列で置き、そのアイコンをポップアップのアンカーにすると必ず起きる。**
`DropdownMenu`・`Popup` 系は「アンカーの下」に開く＝アンカーが**視覚上のヘッダの下端と一致していること**が暗黙の前提。
アイコンを `Alignment.Top` や `CenterVertically` で置いた時点でこの前提は崩れる。

## 掃引状況

- 再現確認＝**M・ダーク・縦・グリッド面**のみ。**未掃引＝明テーマ・横向き・一覧面**。
- **アプリバー直下に ⋮ が残るのは M と J だけ**。D のアプリバー ⋮ は K 形伝播で撤去済みで
  （`ui/BookshelfScreen.kt:1002-1017`）、D に残る ⋮ はカード内（`ui/BookCard.kt:424`）＝アプリバーから約200dp 離れるので
  この症状は原理的に作れない。**K は本棚に ⋮ 自体を持たない**構造。
- ✅ **2026-08-17 に是正済み**＝アンカーをヘッダ行の外へ出し「⋮ の左右端 × ヘッダ全体の下端」に固定した。
  対象は M の `SkyPlate`／`LogPlate` と J の `PortalTopBar`／`GridTopBar` の**4サイト**
  （`GridTopBar` は当初の調査で挙がっていなかった同型の第4サイト）。
- ⚠️ **この修正には機械の網が無い**——`app/src/test/screenshots/` に **M/J の本棚面 golden は1枚も存在せず**
  （`GoldenCoverageTest` が撮影対象外と宣言）、守っているのは**コンパイルが通ることだけ**。
  ⇒ **明テーマ・横向き・一覧面の実機目視だけが残った検証手段**＝`awaiting-human.md` §1-2。
- カード内 ⋮（`BookCard.kt`・`WebBookCard.kt`・`BookshelfK.kt` の `KCardMenuButton` ほか）は**同症状を起こさない**
  ——アンカー Box が操作行またはカード**全体**を包むので、アンカー内に露出する2行目が存在しないため。
