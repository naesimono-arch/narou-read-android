# 粒の「帯」構造は軸まわりガウス配置が本質——一様撒き＋確率棄却では桁違いに再現できない

- 日付: 2026-07-19（高負荷スカイ v6 差し戻し「天の川ではない・ただの散らばった星」の真因）
- 現場: `HighLoadSkyM.kt` の天の川 mid 層

## 事実（数値）

同じ「帯らしさ」の較正値（帯内確率 0.6・帯外 0.3 等）でも、粒の**生成アルゴリズム**が違うと結果は別物になる:

| 方式 | 帯内外の粒密度比 | 見え |
|---|---|---|
| 一様撒き＋確率棄却（帯外も残す） | **1.7 : 1** | 全体に散らばった星（帯として知覚不能） |
| 軸まわりガウス配置（off = gauss()×半幅） | **612 : 1** | 濃い一本の帯（天の川） |

確率棄却は「帯外を最大でも棄却率ぶんしか薄くできない」＝コントラストの上限が棄却率で頭打ちになる。
ガウス配置は粒そのものが軸に集中するため、較正値が同じでも密度比が2桁以上変わる。

## 教訓

- 移植・書き直しで「較正値を同じにしたから等価」は成立しない。**分布を作る機構ごと**移植すること。
- 視覚構造の等価性は目視の前に**数値で自己検証できる**（帯内外密度比・断面ヒストグラム）。委譲時は
  完了条件に数値検証を入れると、実機往復1回ぶんの差し戻しを防げる。
