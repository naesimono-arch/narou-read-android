# 粒ベース背景はブラウザ（HTMLモック）と Compose 実機で見え方が大きく乖離する

**症状**: HTML canvas の粒表現（星野など）はブラウザでは滑らかで美しく見えるのに、同じ粒数・同じ分布を Compose に忠実翻訳すると実機では「まばらな硬い点の散らばり＝荒い」と体感される（2026-07-18 M深空でユーザー所見として顕在化）。

**機序（推定含む）**: ブラウザ canvas はサブピクセル AA・表示スケーリング・ガンマの効きが Compose/Skia の実機描画と異なり、疎な微粒でも「にじんで繋がる」。実機の高密度画面では粒が孤立して解像され、粒間の「未分解星の連続輝き（下地）」が無いことが露呈する。

**対処パターン**: 粒だけで滑らかさを狙わず、**多層化**する——①下地もや（芯に沿う低α soft blob＝未分解星の連続輝き）②本体粒（べき分布）③塵星（細粒）④輝星グロー⑤構造（暗黒帯は全層で間引く）。輝度上限でテキスト可読を担保しつつ、下地は α0.1 未満の極薄で敷く。性能は「生成1回キャッシュ・スクロールは transform のみ」なら粒1万規模でも jank 0%（実測）。

**含意**: 粒ベース意匠のモック承認は「ブラウザで綺麗」を最終合格にしない＝**実機後詰め（ADR 0005 §B）を必須工程**とする。P/J のリッチ化ラウンドでも同じ罠に注意。
