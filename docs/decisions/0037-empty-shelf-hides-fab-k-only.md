# 0037. 空棚では FAB を引っ込める（押す対象を CTA 一本に）— K 固有・D へは伝播しない

- 状態: 採用（2026-08-20 ユーザー裁定）。**K のみ**（Compose 翻訳は別便・申し送りは台帳）。
- 関連: 正本モック `docs/design-candidates/skins/bookshelf-K.html`／同じ日の本棚裁定＝ADR 0036（あちらは D へ伝播する）

## 背景 — 同じ行為の入口が二重にあり、視覚的にも被る

蔵書ゼロの空棚では、中央の空棚 CTA（PDFを追加）と右下の FAB が**同一の行為への入口を二重に置いている**。
初見は「どちらを押すのか」を判断させられ、レイアウト上も両者が被る。

## 決定

**空棚のときは FAB を出さない**（蔵書が1冊でも入れば現れる＝**出没させる**）。押す対象を CTA 一本に整理する。

## 伝播しない境界（なぜ K 固有か）

**D は空棚の本文が「右下の＋からPDFを追加してください」と FAB を名指ししている。**
そのまま伝播させると**本文が指す対象が画面に無い**という壊れ方をするため、伝播には空棚本文の再設計が要る。
よって**今回は K のみ**とする。

**この非対称は忘れやすいので記録する**——同じ 2026-08-20 の裁定でも、端フェード（ADR 0036）は D へ伝播し、
本件は伝播しない。判断の軸は「意匠として良いか」ではなく**そのスキンの文言が FAB を前提にしているか**。
D へ広げたくなったときの前提条件＝**空棚本文の再設計を同便に含めること**。
