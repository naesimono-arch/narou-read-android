# 0036. 本棚の状態チップ行の見切れ＝スクロール端フェード「中」（fontScale 1.0 では発火せず版面不変）

- 状態: 採用（2026-08-20 ユーザー裁定）。**K 正本モックへ反映済み・D 正本へも同強度で伝播**（Compose 翻訳は別便）。
- 関連: 正本モック `docs/design-candidates/skins/bookshelf-K.html` / `bookshelf-D.html`
  （`--fade-w:56px` ＋ `--fade-stops`・`.chipsrow.can-l/.can-r` でスクロール可能な側だけ表示）

## 背景 — フィルタが「あること」に気づかれない

本棚の状態チップ行（すべて／読書中／…）は横スクロールを持つが、**溢れていることを示す手掛かりが無い**。
語彙が増えた条件・fontScale を上げた条件では右端のチップが画面外へ出たまま静止し、
**フィルタという機能自体が発見されない**（見切れの気づきが「たまたま横に払う」に依存する）。

## 決定

**スクロール端フェード・強度「中」**を入れる。
＝**幅 56px・端 18% は地色のまま保ってから緩く抜く**（左右それぞれ、その向きへスクロールできるときだけ出す）。
**D スキンへも同じ強度で伝播する。**

**採用理由は「効く条件」と「効かない条件」が両立していること**＝
**fontScale 1.0 では発火せず版面が一切変わらない**（既定条件のユーザーは何も失わない）。
出るのは実際に溢れている条件だけなので、常設の装飾を増やさずに発見性だけを足せる。

## 却下した代替案

- **弱案（幅 32px・線形カーブ）**: **却下理由は幅不足ではなく線形カーブ**。端から一気に抜けるので
  **「薄い帯」にしか読めず**、「チップがまだ続いている」ことを言わない。
  ＝要件は幅ではなく**端をいったん地色で保つカーブ**の方にある（これが「中」の実体）。
- **FlowRow 2段折り返し**: 溢れそのものは消えるが**縦を食う**。横向きでは高さが枯れている（ADR 0034）ので逆方向。
- **語彙短縮**（チップ文言を短くする）: 効果が薄く、語彙が増えれば再発する対症。
- **現状維持**: フィルタが発見されないままなので却下。
