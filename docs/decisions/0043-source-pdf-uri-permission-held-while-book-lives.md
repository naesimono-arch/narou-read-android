# 0043. 取込元PDF の永続 URI 権限は**本の生存中は保持する**（即時解放をやめる）

- 状態: 採用（2026-09-03 ユーザー裁定）。**実装は未着手**。
- 関連: 実証の証跡＝`docs/verification-shots/source-pdf-delete-2026-09-02/`（エミュ実測）／
  真因のコード＝`PendingJobStore.settlePendingJob` の `releasePersistableUriPermission`・`releaseOrphanedPermissions` の keepUris ②

## 背景 — 「取込元PDFを削除」がアプリを閉じた後は必ず失敗する

取込元PDF の削除は「取り込んだアクティビティが生きている間だけ」効き、アプリを閉じると以後**必ず失敗する**。
しかも失敗の見え方が悪く、**DB の行だけ消えて `/sdcard/Download` の実体が残る**。
真因は `settlePendingJob` が取り込み完了時点で永続 URI 権限を即座に解放していること。

## 決定

**解放を遅らせ、本が生存している間は権限を保持する。**
`releaseOrphanedPermissions` の keepUris ② が既に「本が持っている URI は残す」前提で書かれているので、**実装をその前提へ合わせる**。

**併せて失敗文言を直す**（どちらへ倒しても必要だった項目）＝現在の「移動/削除済みか、削除に対応しない保存先の可能性」は
真因と違うことを言っている。

⚠️ **代償＝端末の永続 URI 権限枠を長く占有する**。上限に当たる兆候が出たら「古い本から解放する」等の追い出し規則を別途要する。

## Why-not

- **② 即時解放を仕様と認め、UI の選択肢そのものを消す（＝閉じた後は選ばせない）**: 実装は軽いが、
  「容量を空けたい」という需要は取り込み直後より**後から**来る。その時に手段が無くなる方を損と見た。
