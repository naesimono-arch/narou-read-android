# 0042. なろうのページを開く場面の注意喚起＝**一度きりのダイアログ**（案A）／「広告」は名指しせず「なろうの表示のまま」で含める

- 状態: 採用（2026-09-03 ユーザー裁定）・**実装済み**（`android/app/src/main/java/com/novelreader/ui/NarouExternalPageNoticeDialog.kt`＝`NarouExternalPageNotice`／`NarouExternalPageNoticeHost`／`NarouExternalPageNoticeDialog`）。⚠️ 旧記述「実装は未着手」は着手前のままだった（2026-09-05 訂正）。
- ⚠️ **範囲の限定（2026-09-04・ADR 0044）**: 本 ADR の「全数確認」が数えていたのは〈なろうで読む〉導線だけで、**PDF 取り込み画面は勘定外**だった。取り込みルートの境界告知は本ダイアログではなく**教示カード 組D の1項目目**が受ける（ADR 0044 決定2）＝このダイアログの呼び手は `WebReaderScreen` の1箇所に限る。
- 関連: 正本モック `docs/design-candidates/candidates/narou-external-page-notice-candidates.html`（案A〜E）／
  規約線＝ADR 0010・0011・0012（加工なし・広告保持・JS 注入ゼロ）／覆す対象＝2026-08-21 の「予告注記を撤去する」裁定

## 背景 — 着地面が「別世界」であることを誰も言っていない

アプリ内から「なろうで読む」を押すと、以後の面は**なろうが配信するページそのもの**になる。
アプリの表示設定もふりがな機能も効かず、広告もそのまま出る。この切り替わりを名乗るものが現在どこにも無い。

## 決定

### 1. 器＝**案A（一度きりのダイアログ・押す前）**

初回だけ出し、チェックで以後を抑止する。背後ではページが読み込まれるので**読み込みの待ち時間がそのまま説明の時間に化ける**
＝体感の追加コストが最も小さい。常設物ゼロ＝なろうの面を 1dp も削らない。

⚠️ **2026-08-21 の「予告注記を撤去する」裁定を覆す**。撤去したのは常設の注記で、本件は初回1回の割り込み＝
毎回の面を汚さない形なら説明責任の側を取る、という切り分けで覆した。

### 2. 文言に含める要素（現行文言は事実誤認を含むので改稿する）

- **ここからは外部サイト（小説家になろう）である**
- **なろうの表示のまま出る**（＝広告を含む。**「広告」の語を名指しはしない**）
- **アプリの操作・表示設定・ふりがな機能は効かない**

⚠️ **旧裁定「『広告』の語は一つも使わない」は覆す**が、覆し方は**一語で含める**＝「なろうの表示のまま」という言い方に
広告を織り込む。名指しの見出しは立てない。

⚠️ **現行文言「ふりがなは付かず」は誤り**＝なろうのページは**作者が付けたルビがそのまま表示される**。
付かないのは**アプリ側のふりがな機能**なので、主語をアプリ側へ直す。

## Why-not

- **案B 常設の帯（−33dp）・案E トップバーが名乗る**: 取り違えが構造的に起きない反面、**URL 追従の実装が必須**
  （`WebReaderScreen.kt:186` は `shouldOverrideUrlLoading=false` で外部リンクへ出られる／取り込みは最後に `pdfnovels.net` へ遷移）で、
  なろうの面を毎回削る。案E はさらに「なろうで読む」の題が消える。
- **案C 直前シート（毎回）**: 毎回の割り込みは初回の説明としては過剰。
- **案D 一過性の帯**: 数秒で退く＝見落とす人には一度も届かない。
