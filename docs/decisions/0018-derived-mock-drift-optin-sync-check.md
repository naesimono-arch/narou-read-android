# 0018. 派生モックの陳腐化は opt-in 実値突合（DERIVED_SYNC）で検知する（コミットゲート hook 不採用）

- ステータス: Accepted
- 日付: 2026-07-13
- 関連実装: `tools/check_design_tokens.py`（DERIVED_SYNC 表＋`css_prop_value`）／派生モックの `@derives` メタコメント
- 関連: ADR 0014（正本の層構造）・ADR 0008（フックのサイレント失敗クラス警戒）

## Context（背景）

派生モック（比較・試作・プレビュー系 HTML）は正本モック（reading-D 等）の値を**複製**して作られるため、正本の更新でサイレントに陳腐化する。実測2件:

1. **F 比較モック**（spacing-scale-compare-D）が正本の本文タイポ 16.5px/2.4 を旧 15.5px/2.3 のまま保持・栞カバーも正本 canvas エンジン未流用の CSS 近似＝ユーザー2度指摘で発覚（2026-07-13）。
2. 本 ADR 実装時の突合初回実行で、**reading-gear-alt-D**（C① 翻訳の起点モック）が「settings-D の .sheet をそのまま再利用（中身は不変）」を自称しながら**離散化前の旧余白値を8箇所**保持していたことを機械検出（padding 10/26→12/32・h2 下 20→24 等）。放置すれば C① の Compose 翻訳に旧値がそのまま流れ込んでいた。

既存の `check_design_tokens.py` は「Compose トークン ⇄ 正本モック」の2層しか突合せず、この第3層（派生 ⇄ 正本）は未検査だった（font-size 検査は全モックの値を1集合にマージするため、正本が正しければ派生の旧値は素通り）。

## Decision（決定）

1. **`check_design_tokens.py` に DERIVED_SYNC 表（opt-in）を新設**し、「正本の忠実再現を**自称する値**」（派生モック内コメントの主張＝色変数の複製・`.sheet` クラスタ等）だけをセレクタ×プロパティ単位で実値突合する。NG で exit 1。
2. 派生モックの `@dsCard` 隣に **`@derives` メタコメント**を置き、複製元と突合の有無を宣言する。意図的に旧値を保存する歴史記録モック（F 比較の「現状」側）は `frozen` を宣言し表に載せない。
3. **コミットゲート hook への配線はしない**（手動運用継続）。本検査は既存のゲート運用（コミット前の habitual 実行・STATUS「ゲート全緑」）に同乗する。

## Consequences（結果と制約）

- 正本モックを更新すると、追従漏れの派生モックが次のゲート実行で NG になる＝drift が silent でなくなる。
- 表は opt-in のため、**並行レーンで増えるカタログ系モックには一切干渉しない**（載せない限り検査対象外）。新たな比較・試作モックを「正本の忠実再現」として作ったら DERIVED_SYNC へ行を足すのが保守規約。
- 値の複製 drift は捕まえるが、**構造的複製ズレ**（canvas エンジン未流用の CSS 近似等）は値突合の射程外＝レビュー・目視で守る。
- 派生モックが役目を終えて歴史記録化したら（例: C① 翻訳完了で gear-alt が reading-D へ吸収された後）、表から外し `frozen` へ切り替える。

## Alternatives（採用しなかった案と理由）

- **コミットブロック hook（PreToolUse で check を走らせ NG なら deny）**: 発生頻度1回のリスクに常設の機械ガードを立てると、ガード自体の保守コスト（配線のセッション固定 task_diary #48・偽陽性対応・撤去判断）がリスク本体を上回る＝人間センチネル撤去と同じ裁定。drift 見逃しの真因は「走らせ忘れ」でなく「検査項目の不在」であり、価値の9割はロジック側にある。走らせ忘れ起因の drift が再発したら再検討。
- **PostToolUse で「要再同期」警告（additionalContext）**: そのターン限りで永続ゲートにならず、ADR 0008 が警戒するサイレント失敗クラスを太らせる（task_diary #28 の教訓そのもの）。不採用。
- **opt-out（全派生モックにメタ・突合必須）**: 別 worktree のカタログ増産がマージ時に軒並み NG になる。不採用。
- **「最終同期日」メタでの管理**: 日付は手動更新で必ず陳腐化する＝実値突合で代替。
