# 0001. Hilt（DIフレームワーク）不採用

> 旧 `task_diary.md` §22（意図的に採用しなかったアーキテクチャとその理由）

**Status**: 採用済み（不採用の判断）

## 判断

**Hilt（DI フレームワーク）は不採用**。

## 理由

依存グラフが `Application → Repository → ViewModel` の一直線に近く、手動 DI で 10 分以内に管理可能な規模。フレームワーク導入のコスト（ビルド時間・学習・ボイラープレート）が、得られる依存解決の自動化に見合わない。
