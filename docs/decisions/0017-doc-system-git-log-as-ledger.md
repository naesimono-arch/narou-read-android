# 0017. 管理ドキュメント体系の再編——完了履歴は git log・CLAUDE.md はルーター・番人は機械

- 状態: 採用（2026-07-12・ユーザー裁定）
- 関連: `STATUS.md`/`handover.md` 冒頭凡例・CLAUDE.md「管理ドキュメントの体系」・`docs/knowledge/README.md`・stale-check `check_size_budgets`

## 背景（定量診断）

git 履歴と台帳の実測で、文章管理が開発の主役になっていた:
直近200コミットの **35% が docs 専用**・変更頻度1位2位が handover/STATUS（最頻コードファイルの3倍）・
3台帳のうち毎セッション価値があるのは **15〜20%**（残りは git/plans に正本がある二重管理か完了ログ）・
3台帳とも行数は単調増加で刈り込み不全。CLAUDE.md はプロジェクト＋グローバルで毎ターン約30KBの固定費だった。
（外部基準: `/mnt/c/Users/qingj/Desktop/project/claude-bestpractice/claude-md/knowledge/01-principles.md`＝指示予算 ~150-200・削減テスト・「ルールは罠であって地図でない」）

## 決定

1. **完了の履歴は git log（コミットメッセージ）が正本**。SHA・レンジ・件数・差分行数・コミット表を台帳へ手書きしない。台帳更新は原因の論理変更と同じコミットに同梱（docs 専用コミットの廃止）。
2. **STATUS.md ＝現在値のみ（目安60行）**。完了済み節を持たない。**handover.md ＝やることのみ**（完了は打ち消し線で残さず消す）。
   ※ **追記 2026-07-30**: この「やることの台帳」は **ADR 0028 で「待ちの種類」により二分**した——
   `handover.md`＝Claude が今すぐ動けるもの／`awaiting-human.md`＝人間の目視・裁定・外部手続き待ち。
   完了を消す運用と、本 ADR の他の決定は不変。
3. **CLAUDE.md はルーターに徹する**（スキル/フック/memory への1行ポインタ＋モデルが知り得ない罠のみ）。手順に育った節はスキルへ追い出す（実例: UI意匠節→`/visual-language`）。
4. **新規知見は `docs/knowledge/` に1知見=1ファイル**。`task_diary.md` は凍結アーカイブ（#N 参照は有効・追記停止）＝連番の二重採番クラスを構造的に消す。
5. **規約は機械の番人とセット**で運用する（stale-check `check_size_budgets`＝STATUS 行数・handover 打ち消し線・CLAUDE.md バイト予算。宣言だけのルールは数週間で崩れることを大掃除前の実測が示した）。

## 併せて撤去したもの（Why-not＝テスト強制3点フック）

`check_commit_granularity` / `check_lint_on_commit` / `mark_kotlin_tests_passed` を撤去（ユーザー裁定）。
**理由**: ROI 2基準〈その事故は実際に起きたか／不可逆コスト×頻度＞保守税か〉に照らし、コミットは可逆・テストは再実行可能で②が不成立。lint ゲートは正本環境（/mnt/c＝drvfs）でサイレントスキップされ事実上無効だった。
**残すもの**: ブランチ保護センチネル系（main 直コミットは push 後に不可逆化）・破壊的マイグレーションブロック（蔵書DB消失＝不可逆・実事故あり）・捏造検知（誤完了報告に基づく判断＝検出困難な不可逆）。
CLAUDE.md の「自己検証必須（testDebugUnitTest）」は**書かれたルールとして存続**——執行はフックでなく規律に戻す。

## 却下した代替案

- **task_diary の全面分割移行**（既存 #N を全部ファイル化）: ADR・コード・memory からの #N 参照が多数あり、張り替えコストと参照破壊リスクが便益を上回る → 凍結＋新規のみ新方式の段階移行を採用。
- **STATUS §1（完了ログ）の圧縮保持**: 完了の一行説明はコミット件名が既に持っており（件名中央値58字の運用実績）、圧縮しても二重管理のまま → 全廃してポインタ化。
- **docs 専用コミットの継続**: 実装コミットへの同梱で往復（提示→承認→コミット）が1回で済み、docs→docs 数珠つなぎ（最頻遷移35回）が消える → 同梱へ変更。
