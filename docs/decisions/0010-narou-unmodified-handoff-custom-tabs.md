# 0010. なろう作品の閲覧は「加工なし送客（Chrome Custom Tabs）」を既定とする（WebView 内包・本文ネイティブ描画は不採用）

- 関連知見: `task_diary.md` #45（なろう運営ヘルプ183「よくある違反行為」の原文・根拠条項）

> **適用範囲の注記（2026-07-09）**: 本 ADR が塞ぐのは「閲覧ページの WebView 内包・独自UI 被せ・本文ネイティブ描画」であり、"閲覧"用途に対して有効。公式が用意した**縦書きPDF DL 機能の操作**という別用途については ADR 0011 が WebView 限定再導入の例外を定義する（両立）。
>
> **更新の注記（2026-07-11・ADR 0012）**: "閲覧"の送客先の既定は、機能②（読書位置の記録・続きから再開）の対象範囲について ADR 0012 が Custom Tabs から「**加工なし・URL 観測のみ・JS 注入ゼロの WebView**」へ更新した。本 ADR の禁止本体（"加工"＝広告除去・CSS/DOM 改変・本文の機械的取得）は覆っておらず、0012 はむしろそれを 0011 より厳格に守る（注入を一切しない）。ヘルプ183 が「加工なし WebView 表示は問題としない」を明文で許容している点が根拠。下記 Decision 1 の「Custom Tabs を既定」は、なろう作品読書については 0012 が上書きする（PDF 蔵書の継続カードは当面 0010 のまま据え置き＝0012 スコープ外）。

## Context（背景）

なろう公式APIの発見機能を「第2の柱」に育てる計画では、当初「Web 閲覧系の導線（継続読書・なろうで読む）を**アプリ内 WebView で完結**させ、独自UIを被せて没入させる」ことを構想していた（2026-07-07 時点の設計方針）。

2026-07-08 になろう運営の開発・運営者向けヘルプ183「よくある違反行為」を一次確認した結果、この構想は**なろうに対しては構造的に塞がれている**ことが判明した（原文・根拠条項は task_diary #45 が正本）:

- **問題としない**（原文）: 「WebView 及び類似の技術を用いて、作品の閲覧ページを**加工することなくそのまま**当該アプリ内で表示する行為」。
- **違反（確認され次第 強制退会・削除等）**（原文）: 「掲載作品の閲覧ページにて**広告を除去する等の加工**を行って表示する行為」／「掲載作品の本文を**機械的に取得**して表示・ダウンロードする行為」。

罠の要点は、禁止の本体が"広告除去"ではなく **"加工"そのもの**（条文は「広告を除去する**等の**加工」）である点。フォント・配色・余白の CSS 注入も、ヘッダー/広告の DOM 除去も、**見た目を変える一切が"加工"に該当**し、広告を残しても違反になる。したがって「独自UIを被せる WebView 内包」は原理的に不可、本文をネイティブ描画する道も「本文の機械的取得」で違反となる。

## Decision（決定）

1. なろう作品の閲覧は **Chrome Custom Tabs による「加工なし送客」を既定の解**とする。用途が"加工なし表示"に限られる以上、フル WebView を自前で抱える利点はほぼ無い。
2. **独自UIを被せる WebView 内包・本文のネイティブ描画は採らない**（＝**案A＝本文非取得・メタのみ**を堅持。規約面からも案Aが正しいことの裏付けが得られた）。
3. 意匠・没入の作り込みは**権利を自前で持つ PDF 読書面に集中**し、なろうは「発見（メタ）＋加工なし送客」に徹する（ADR 0005 の適用範囲とも整合）。

## Consequences（帰結）

- 現状 Phase 3 の外部ブラウザ送客（C4 と同方式）は規約セーフのまま維持でよい。アプリ内寄せするなら Custom Tabs へ引き戻す（素の `Intent.ACTION_VIEW` から Custom Tabs へ格上げしても"加工なし"は保たれる）。
- 「アプリ内 WebView で完結」を前提にしていた融合本棚の(b) Web由来カード等の導線設計は、**加工なし送客前提で再設計**する（handover「Phase 4 残り」に注記済み）。

## Why-not（採らなかった選択肢）

- **素の WebView で内包**（広告を残せば加工なしでは？）: WebView は後から `evaluateJavascript` で"加工"でき、運営に対し"無加工"を**仕組みで保証しにくい**。構造的に加工不能な Custom Tabs の方が安全。有料の広告除去オプションは存在せず、運営意思は「広告は消させない」で一貫している（明文が無くても運営意思・収益基盤に反する行為は不可、という読みの裏付け）。
- **本文をネイティブに取得して自前描画**（究極の没入）: 「本文の機械的取得」に真正面から抵触（14条23項）。案A（本文非取得）の放棄はそもそも規約違反であり検討に値しない。
