## 4. 結論: 「作者差が支配的＝全角正規化は一般則でない」の実測根拠

1. **半角英数記号は9作品すべてで0 run**。「SF・半角英字の宝庫」と目された N3957FQ ですら**半角ASCII は文書全体で0字**、
   略号・型式・結社名はすべて全角（ＡＷ/ＯＬＥＭ/Ｅ．Ｇ．Ｆ）。→ v1縦中横（半角対象）は新蔵書でも**発火しない**（P0-2 の旧結論を6作品で再確認）。

2. **「全角へ寄せれば済む」は成り立たない**。全角化で吸収できない**単幅の非ASCII**が作者ごとに大きく出没する:
   - ギリシャ文字(U+03B1..)は N3957FQ=629・N0833HI=14・N2367FS=7 と偏在、N9463BR/N8809BK/N7038HV=0。
   - ローマ数字(U+2160..)は N9463BR=107・N3957FQ=71 に集中、他は0〜1。
   - ダブルミニュート〝〞(U+301D/U+301E)は **N8809BK だけ**が593対、他8作品は完全に0。
   これらは「全角正規化」の射程外で、**作品を跨ぐと分布が総取っ替えになる**（＝一般則にできない）。

3. **同一作品内でもコードポイント異体が位置で割れる**。波ダッシュは3作品とも**見出し=～U+FF5E／本文=〜U+301C**に分かれ、
   単一の正規化テーブルでは統一できない。ダッシュも ―(U+2015) を N9463BR は単体2,015個使う一方 N3957FQ は本文0（章題側で使用）。

4. 縦書き組版が実データで確実に踏むのは、**全角＝正立**（数字run/英字run/！？run が主役: 新6計で全角数字11,174run・全角英字9,151run・全角！？39,280run）に加えて、
   **作者依存の単幅特殊字（ギリシャ・ローマ数字・〝〟・波ダッシュ2種・―連続）**。これらは縦中横ではなく**正立/回転/連結の個別処理**が要る。
   よって「入力を一律に全角へ正規化してから組む」という単純化は**採れない**——作者差が支配的なため、文字クラス判定は
   コードポイント単位（U+2015, U+301C, U+FF5E, U+301D/E, ギリシャ/ローマ数字ブロック）で持つ必要がある。
