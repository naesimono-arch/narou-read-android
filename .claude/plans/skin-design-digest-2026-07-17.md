# スキン設計ダイジェスト（2026-07-17）

UIスキン候補モック量産ループ用の正本圧縮版。原典＝`/mnt/c/Users/qingj/Desktop/project/UX/Design/`（全11枚）。
**普遍則のみを載せる**。D和モダン固有の値（特定色コード・署名要素）は§A末尾の「D固有（混ぜるな）」に隔離した。
なぜ隔離するか＝スキンは別の美学（例: C夜行）を持ちうるが、下記の普遍則は読書アプリの機能要件・正本規律に接地しており全スキン共通だから。

## §A 生成ブリーフ用規範（モック生成エージェントのプロンプトへそのまま貼る）

### 配色・トークン思考
- **色は意味で参照する**。値はprimitive、意味はsemanticスロット（`accent.structure`等）。UIは意味語を参照し、見た目語（`blue`）で参照しない（青を変えた日に名前が嘘になる）。
- **hueは少なく、段は多く**。hueごとに9段スケールを一度だけ彫り、以後は消去法で選ぶ（base=500→両端900/100→知覚的中間で埋める）。`lighten()`/`darken()`の動的生成は禁止（野良値の温床）。
- **純白×純黒を彫らない**。最暗段も僅かに色味を持つ濃色から（長文で最大コントラストはハレーションを招く）。
- **色地の上の前景をalpha減衰で作らない**（`copy(alpha=`禁止）。背景と同hueのまま彩度・明度を動かした専用シェードを彫る。ダーク/セピアは全画面が「色地」＝この規則が全域に効く。
- **同一semanticスロットがテーマ間で同一primitive段を参照したら違反**（地が違えば正しい前景の段も違う。「ライトとセピアが同じに見える」の機械予防）。
- **装飾目的の新色追加は原則改訂級の重さ**（＝ADRが要る）。署名要素の装飾枠は1種類まで。
- **状態バリアント（pressed/disabled/ダーク/セピア）のスロットを最初から彫る**。後付けは命名が乱れる。

### 日本語組版（読書アプリ特有・**スキンの美意識で上書き不可＝規格/研究値の層**）
- ルビ＝親文字の1/2サイズ。モノ/グループ/熟語ルビ。はみ出しは前後の漢字に掛けない・隣接ルビを連続させない（JLREQ）。
- 行頭/行末禁則を守る。行間は**0.5〜1em（JLREQ標準域）**、行間は行長に比例・フォントサイズに反比例で持つ（固定値でなく関数）。
- 和文letterSpacing=0（Material既定の欧文字間は広すぎ）。例外は英字ラベル/略語（PDF・TOC）のみ。
- 本文16sp以上・sp尊重（dp固定は禁じ手、フォントスケール1.3〜2.0で破綻しない）。和文行長は40字前後が設計域。
- **本文コントラストは全テーマで4.5:1以上**（沈める表現＝4.5:1未満が許されるのは補助・装飾情報だけ）。アクセシビリティ最低線＞美学。
- ライト/セピア/ダークの3点セットが事実上の標準装備。ダーク面は純黒でなく9:1前後・僅かに浮かせた暗面。
- 見出しは続く本文に密着＝上余白>下余白（浮いた見出しはどちらの節か曖昧）。

### 視覚階層（沈めて立てる・一画面一強調）
- **一画面一強調**（判定則＝強調が2つ同格なら違反）。達成手段は**強調を足さず、競合要素を沈めて作る**（主役に色/影/サイズを足さない。階層のインフレを断つ）。
- 強調の3通貨＝**サイズ・ウェイト・コントラスト**。テキストは色3段×ウェイト2段でほぼ足りる。サイズ差は最後の手段。
- **font weight 400未満を使わない**（小サイズで線が消える）。沈めるのは色かサイズで。
- **ラベルは最終手段**（省く→値に言葉を吸収「あと3話」→沈めて添える→スペック表だけ例外）。`ラベル:値`の列挙は階層を殺す。
- アクションのピラミッド＝Primary（solid・1画面に1つ）/Secondary（outline・少数）/Tertiary（リンク状・残り）。**destructiveを常時赤ボタンにしない**（赤が主役になるのは確認ダイアログで初めて）。
- 全行がリンクの画面（目次等）は色で塗ると画面全体が立つ→色でなく濃度・マーカーで階層を作る。
- 視覚階層と文書階層（semantics）は独立。視覚的に沈めた見出しもsemanticsではheading宣言（連動禁止）。
- 群を線でなく余白で示すなら**群の外の余白≥群の中の余白**（曖昧な余白を作らない）。
- 影ゼロでも明暗で深さは出せる（明面＝手前・暗面＝奥）。区切りに影・二重線・太線を使わずヘアライン（1px/最細・`outlineVariant`相当）で。

### モーション（静謐の数値枠）
- **motionは意味への課金**。因果/空間/連続性/進行の4類型のいずれかを説明しない動きは装飾＝duration 0。①〜③は1回きり・有限、④進行のみループ可。
- **enter減速・exit加速、exitはenterより短く**。戻る操作は入場の逆再生。
- 数値定数: 因果100ms以内に開始・Doherty 400ms（アニメ込みで次状態が使える）・16.6msフレーム予算（カクつく動きは削る）・700ms超は固まって見える。**単発durationの上限350ms**（超えるスロットを彫らない）。
- 頻度の高い操作ほど短く（最頻＝ページ送りは即時に近づける）。非ブロッキング（連打で次々進める）。
- overshoot/bounce/springの振動禁止。装飾ループ・自動再生・注意喚起の揺れ（パルス/明滅/シェイク）禁止。**stagger（順次入場演出）しない＝一画面一動き**。
- 位置・大きさが動く（spatial）のは空間/連続性を説明するときだけ。単なる状態変化（色・選択・表示切替）はfade（「迷ったらフェード」）。テーマ切替は全画面一括crossfade（色トークンが同一値で動く）。
- **reduce-motion（アニメ削除設定）でも全機能が成立**すること＝アニメでしか伝わらない情報を作らない。
- duration/easingの直書き禁止（`tween(300)`は生色コード直書きと同罪）。
- 注: 「装飾motionを一切持たない」は静謐系スタンス。表情の強い演出（M3 Expressive方向）は対極の設計思想として存在する（スキンが選ぶ美学の軸）。ただし上記の数値床（Doherty/16.6ms/reduce-motion）はスタンスに関わらず不変。

### 没入とchromeの規律（読書画面）
- **読書画面の既定値は「無」**。chrome表示はユーザーが道具を要した例外状態で、用が済めば退く。ただし「呼ぶ手段」と「戻る保証」は失わない。
- 呼び出し＝**画面中央タップでトグル**（左右はページ送りに予約）。退場も同じ中央タップ（対称）。**タイムアウト自動退場はしない**（ユーザーが出したものをアプリが勝手にしまわない）。
- 消えている間も残す最小情報は3問で決める＝**随伴（読む行為に付随）・一瞥（視線を止めず読める）・静けさ（動かない・本文より沈む）**。現在位置は残す・本文より確実に沈める。
- システムバーとアプリchromeは同時に出入り。端スワイプで一時バーを呼び戻せる（`BEHAVIOR_SHOW_TRANSIENT_BARS_BY_SWIPE`＝閉じ込めない）。
- **版面（テキスト領域）はdisplayCutout/safeDrawingの内側**、地色だけ全画面まで広げてよい。バー出入り・immersive遷移で**本文をリフローさせない**（読んでいる行を見失う最悪の違反）。chromeは本文にオーバーレイ。
- アプリ内輝度はWindow属性（画面限定・離脱で自然にシステム値へ戻る）。システム輝度・端末ダーク設定を書き換えない。keepScreenOnは読書画面のみ・離脱で解除。
- **実証のない効能を謳わない**（「ブルーライトカットで目を守る」は不可。言えるのは「暗所でまぶしくない夜間テーマ」）。

### 和モダンの「間」（普遍化した部分）
- 余白は「余り」でなく**能動的な構成要素**。要素追加のために既存余白を縮める変更は原則否。
- 余白は離散スケール（例4/8/16/24/40）のみ・任意値禁止。スケールの本質は倍数でなく相対差＝**隣接値が互いに25%以上離れる**（120と125を裁ける。新値追加はこの25%則で昇格審査）。
- 装飾は「必要が証明されたものだけ」（色数・線・影・動きの抑制）。強調の予算は小さく、しかし置く場所には惜しまない（沈黙が目的ではない＝強調ゼロと混同すると死ぬ）。

### D固有（混ぜるな＝Dスキン専用の値。他スキンのモックに流用しない）
- パレット: 素地`#FBFAF8`・墨`#1C1F26`（純白純黒回避）・藍`#1C3D5A`（主アクセント/構造）・青磁`#9CB3A8`（副次）・ダーク面`#14171C`・セピア`#F2E7CE`。
- 本文16sp/行送り28sp（行間0.75em相当）。明朝＝コンテンツの声（題字/本文/章見出し）、ゴシック＝道具の声（ラベル/ボタン/メタ）。
- 署名要素: 藍の縦ルール（accent border技法の限定運用）・静かな縦グラデ書影・実画像を捏造しない。
- 静謐＞演出／色は3色（素地・墨・藍＋補助の青磁）で閉じる——これはD（和モダン）の原則であり、別美学のスキンには適用しない。

## §B 検収チェックリスト（監督がモックHTMLを審査：観点→合否基準）

### トークン・配色
- 野良値検査: 全色/フォント/余白値を列挙 → トークン外の値（スケールに無い色・任意dp余白）が無いこと。
- 直書き相当: `copy(alpha=`で色地上の前景を作っていない／font weight 400未満が無い → ヒットゼロで合格。
- テーマ間差: 同semanticスロットがライト/セピア/ダークで別段を参照 → 同一段参照があれば違反。
- 新色: 装飾目的の新hue追加が無い（署名装飾は1種類まで）→ 追加あればADR要求。
- spacing新値: 隣接値と25%以上離れている → 満たさなければ違反。

### 視覚階層
- 強調の予算: 視覚的強調を強い順に列挙 → 2つ以上同格なら「一画面一強調」違反。
- **グレースケール検査**: グレースケール化して強調順位を再列挙 → 色ありと順位が入れ替われば「色が階層を独りで背負っている」違反（余白/コントラスト/サイズが仕事をしていない）。
- 群余白検査: 区切り線の無い群すべてで「外の余白>中の余白」（見出しは上>下）→ 逆転/同値は曖昧な余白違反。
- ラベル: `ラベル:値`の行列が無い（スペック表以外）→ あれば階層死の違反。
- アクション: Primaryが1つ・destructiveが常時赤で座っていない → 満たさなければ違反。

### 組版・可読性
- 本文コントラスト概算 → 意味を運ぶテキストが4.5:1未満なら違反（沈めてよいのは補助/装飾）。
- letterSpacing=0（和文）・行間0.5〜1em・ルビ1/2サイズ・見出し上余白>下余白 → 各々満たすこと。

### モーション（動きを含むモック/仕様のとき）
- 各アニメの意味類型（因果/空間/連続性/進行）を1語で言える → 言えない動き＝装飾はゼロ。
- exit≤enter・戻るは逆再生・350ms超が無い・ループはprogress相当のみ・stagger無し → 各々満たすこと。
- reduce-motion時に全フロー成立（アニメだけが運ぶ情報が無い）→ 満たさなければ違反。

### 没入・chrome（読書画面のモックのとき）
- chrome非表示が既定・トリガーが対称トグル・タイムアウト自動退場が無い → 満たすこと。
- 没入中の残存最小情報が随伴/一瞥/静けさの3問を通り本文より沈む（3テーマ）→ 満たすこと。
- 版面がcutout/バー領域と重ならない・バー出入り前後で本文レイアウト同一 → リフローは違反。
- 実証のない効能表示が無い → あれば違反。

### 状態網羅・原典整合
- 状態の欠落: 空/読込中/エラー/選択中/ダーク/セピア/没入中のうち未定義を列挙 → 宿題として報告。
- 疑問符監査: 初見3秒の内心（「押せる?」「どっちの意味?」）で不明瞭要素を列挙 → self-evident/self-explanatory/不明瞭の3段階、不明瞭は違反。
- 修正案の語彙規制: 強調不足の修正案は「◯◯を目立たせる」でなく「◯◯以外を沈める」を第一案に（主役への加算案は禁止則との衝突を先に検査）。
