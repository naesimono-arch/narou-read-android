### A. アクセント色が3系統に分裂

**指摘**
FAB・スライダーはサーモン、設定の選択チップは青灰、目次の現在地はえんじと、主役色が画面ごとに違う。「一貫性」を最も下げている要因。

**提案**
アクセントは1色に統一。実質ブランド色のサーモン系へ寄せ、選択チップ・目次ハイライト・進捗バー・スライダーに同色を適用。この1点が一貫性に最も効く。

**妥当性: ◯ 概ね妥当（色名は補正要）**
- FAB／スライダー = `primary` 朱墨 `0xFF7B3F2A`（≒サーモン）→ 指摘どおり。
- 選択チップ = M3 FilterChip既定で `secondaryContainer = 0xFFDCE4F0`（青鼠）→ **指摘の「青灰」は正しい**（`Color.kt:18`）。
- 進捗バー = `tertiary` 緑青 `0xFF4A7C6B`（`Color.kt:21`）→ 指摘が見落とす第4の色。
- 目次の現在地 = `accent`。LIGHTでは `0xFF7B3F2A` で **primaryと同一の朱**（`Theme.kt:57`）→ 指摘の「えんじ＝第3アクセント」は**不正確**（既にprimaryと統一済み、濃い朱がえんじに見えただけ）。
- 結論: 「主役色が複数併存」の核心は妥当（朱／青鼠／緑青）。ただし青鼠・緑青はM3 secondary/tertiaryの役割色。**緑青は「進捗/完了」の意味色なので1色統一で意味区別が消える点は要検討**。

### B. 削除アイコンが常時表示

**指摘**
本棚の全カード／全行にゴミ箱が出ている。タッチ機ではカバー鑑賞を妨げ、視覚ノイズと誤タップ（誤削除）リスクを生む。

**提案**
長押し→コンテキスト操作（Material標準）か オーバーフロー「⋮」へ格納。カバーを純粋な「表紙」として見せられる。

**妥当性: ◎ 妥当（確認済）**
グリッド・リスト両方で `Icons.Outlined.DeleteOutline` を常時描画（長押し/⋮ではない）。`BookshelfScreen.kt` グリッド ~406-427／リスト ~582-589。

### C. 著者名が重複している

**指摘**
グリッドはカバー上＋タイトル下、リストはサムネイル内ラベル＋行内と、著者名が2〜3回出ている。

**提案**
著者は1か所に。自動カバーからは著者を外し、頭文字＋色だけの「背表紙」に徹させる。

**妥当性: ◎ 妥当（確認済）**
`BookCover` 内（`BookCover.kt` ~122-133, `alpha 0.70`）＋カード本文側（グリッド ~441-449／リスト ~544-552）で両モードとも著者名が**2回**描画。

### D. 読書chromeが没入を弱める

**指摘**
上部のトープ色バーと下部の操作バーが常時固定。読書ファーストのアプリでは没入型chromeが定石。

**提案**
中央タップで表示/非表示、スクロールで自動退避、不透明ブロックでなく半透明/ブラーに。評価軸①「没入感」へ直接効く。

**妥当性: △ 前提に誤りあり（一部すでに実装済み）**
- **トップバーは既にスクロール自動退避する**（`enterAlwaysScrollBehavior` ＋ 自前 `NestedScrollConnection` ＋ `graphicsLayer{translationY}`。`NativeReadingScreen.kt:351-410, 479-484`）→ 指摘「上下バー常時固定」は**トップバーには当てはまらない**。
- ボトムバーは固定だが既に半透明（`alpha 0.95`、`NativeReadingScreen.kt:419-420`）。
- トップバー背景はトープ `0xFFD4B896` ≠ 本文クリーム `0xFFFCFAF2`（`Theme.kt:49,45`）→ **色のズレは指摘どおり妥当**。
- **未実装で有効な残提案に絞る**: ①中央タップで表示/非表示トグル ②ボトムバーも退避 ③ブラー ④バー色を紙トーンへ寄せる。

### E. 章タイトルの省略処理が粗い

**指摘**
読書画面のタイトルは文字の途中で切れ、目次では末尾に「－」が残る行がある。

**提案**
省略記号（…）で統一。目次は縦の余裕があるので、切るより2行折り返しが読みやすい。

**妥当性: ◎ 妥当（ただし目次の「－」はパース層）**
- 読書タイトル: `maxLines=1` かつ `TextOverflow` 未指定 → 既定 `Clip` で**文字途中で切れる**（`NativeReadingScreen.kt:485-495`）。
- 目次: `maxLines` 無しで自由折り返し（`NativeTableOfContentsScreen.kt`）。末尾「－」はUI側でなく **`entry.title` をそのまま表示しているため＝抽出/パース層の残渣**。除去は読書UIでなくパース層が対象。

---

### F. 自動生成カバーの質

**指摘**
「頭文字＋色」の発想は良いが、オリーブ/ブラウンがくすみ、薄い文字の重ね（ウォーターマーク）がノイズになっている。

**提案**
彩度・明度を揃え色相だけ振った調和パレットへ。ウォーターマークは削除、グリフの太さ・配置を整え、わずかな紙質感で「本」らしさを。

**妥当性: ◎ 妥当（確認済）**
`BookCover.kt` は HSL(hash由来)で色相生成、明度 0.38〜0.50 で「くすみ」やすい。ウォーターマーク = 文字 `alpha 0.08`（確認済）、著者 = `alpha 0.70` でカバー上に描画。→ ウォーターマーク削除・著者をカバーから外す・パレット調律はいずれも妥当。

### 01 アクセント色統一（A）— `feat`

実態は**チップの選択色だけ**の変更で済む（目次accent・スライダー・FABは既に `primary` 朱、進捗バーは決定により緑青のまま）。

- **対象**: `NativeReadingScreen.kt` の `ReadingSettingsSheet` 内 `FilterChip`（colors 未指定→M3既定で選択時 `secondaryContainer`=青鼠になっている）。
- **実装**: `colors = FilterChipDefaults.filterChipColors(selectedContainerColor = MaterialTheme.colorScheme.primaryContainer, selectedLabelColor = MaterialTheme.colorScheme.onPrimaryContainer)` を渡し朱系へ寄せる。`selectedBorderColor` も要調整なら `FilterChipDefaults.filterChipBorder`。
- **やらないこと**: 進捗バー(`tertiary`)・目次accent・スライダー・FAB は変更しない。
- **コミット**: 1本（`feat: 設定チップの選択色をアクセント(朱)系に統一`）。

### 02 カバーからウォーターマーク＋著者を削除（C/F）— `refactor`

- **対象**: `BookCover.kt`。①ウォーターマークの `Text(... alpha 0.08f)` を削除。②著者の `Text`（下部中央, alpha 0.70f, 目安 ~122-133）を削除。
- **著者の一本化**: 著者表示はカード側（grid 目安 ~441-449 / list ~544-552）に既にあるのでそれを残す。
- **引数整理**: `BookCover` の `author` 引数が未使用化したら引数を削除し、呼び出し側（grid/list）も合わせて修正。
- **why コメント**: 「著者はカード本文に一本化したためカバーからは外す」を残す。
- **コミット**: 2本（`refactor: 自動生成カバーのウォーターマークを削除` / `refactor: カバーから著者表示を外しカード側に一本化`）。

### 03 削除UI 両方式＋切替トグル（B）— `feat`

評価用に**両方式を実装し実行時トグルで切替**。確定後に片方＋トグルを消す前提。

- **状態の永続化**: `BookshelfScreen.kt` の既存 SharedPreferences パターン（`app_prefs`、`is_grid_view` と同様、目安 :93/:101/:179-182）に倣い、キー `delete_ui_mode`（Int: 0=長押し / 1=⋮）を追加。
- **トグルUI**: 本棚 `TopAppBar` の `actions`（目安 :177-189、グリッド/リスト切替の隣）に切替 `IconButton` を追加。
- **出し分け**: `GridBookCard` / `ListBookCard` の常時表示 `IconButton`(削除) を mode で分岐。
  - `mode=1（⋮）`: アイコンを `Icons.Filled.MoreVert` にし、`DropdownMenu` に「削除」項目。
  - `mode=0（長押し）`: 削除アイコンを消し、`Card` に `Modifier.combinedClickable(onClick=onOpen, onLongClick=...)` で `DropdownMenu`（または選択モード）を出す。
- **据え置き**: `onDelete`（目安 :248/:271 → `bookToDelete = book` → 既存の削除確認ダイアログ）はそのまま流用。
- **why コメント必須**: 「2方式を比較評価するための一時機構。採用方式が決まったら他方とトグルを削除する」と明記。
- **コミット**: 1〜2本。
